# 测试与验收

## 必跑

```bash
npm run check      # node --check + go vet
```

启动本地服务后（`npm run dev`）手动走一遍：

1. 首屏：种子会话自动流式播放，思考 → 工具 → 正文 → 产物/提问出现。
2. 发送消息：Enter 发送、Shift+Enter 换行；停止按钮可中断；停止后内容保留。
3. 提问卡片：点选项 / 键盘 1–3 / 「其他…」自定义；已回答态禁用。
4. 产物：点击打开右侧文件面板；对话变窄；树可展开、键盘导航、点文件看到代码；拖宽、关闭恢复。
5. 代码灯箱：面板「全屏」打开；Esc 关闭；复制可用。
6. 设置：外观（字号/动效/侧栏）、对话（流式速度/思考展开）、数据（导出/恢复/清空）、用量页。
7. 看板：整页高度、返回对话；天气/建议/任务/进度数据齐全。
8. 响应式：390 / 600 / 1100 无横向滚动；面板在窄屏覆盖。
9. 减少动效：无打字光标、无循环动画。

## 自动冒烟

```bash
npm run smoke
```

`scripts/smoke.mjs` 先 `go build` 出后端二进制，再用 `GQY_MOCK=1` + 临时 `GQY_HOME` 起服务端，配合无头 Chrome（CDP，无依赖），跑 20 项：

| 覆盖 | 断言 |
| --- | --- |
| 后端 | `go build` 通过；`/api/health` 返回 `provider: mock` |
| 静态边界 | `/server.go`、`/package.json`、`/scripts/*`、`/.env` 全部 404；错误方法 405 |
| 首屏 | 种子会话渲染、服务端状态探测为“已连接” |
| 流式 | 真实 SSE 链路：正文、思考块、工具轨迹、发送键复位、无错误态 |
| 落盘 | `$GQY_HOME/sessions/<id>/` 有 `manifest.json`、`messages.jsonl`、`logs/tools/*` |
| 安全 | `javascript:` 链接被降级成纯文本 |
| 面板 | 产物卡片 → 文件面板 → 代码渲染 |
| 设置 | 五个 tab 全部可切换；导入/导出按钮存在 |
| 看板 | 9 个任务 + 环形进度 |
| 快捷键 | ⌘/Ctrl+K 打开搜索、Esc 关闭、Alt+N 新会话 |
| 草稿 | 切换会话后草稿恢复 |
| 导入 | 导出结构可原样回灌并重载状态 |
| 控制台 | 全程无 error |
| 真实上游 | 假的 OpenAI 兼容上游 → `thinking` / `text` / `usage` 映射正确 |

需要本机有 Go >= 1.22 和 Chrome / Chromium；缺任意一个时脚本会打印“跳过”并以 0 退出。设置 `CHROME=/path/to/chrome` 可指定浏览器路径。

## 手动回归（改动 UI 时）

1. 首屏：种子会话自动流式播放，思考 → 工具 → 正文 → 产物/提问出现。
2. 后端三态：`npm start`（无密钥）、`GQY_MOCK=1 npm start`、填好 `.env` 后 `npm start`，模型按钮与关于页文案随之变化。
3. 断网/错误：把 `GQY_API_BASE` 指向不存在的地址，确认错误卡片出现且“重试”可用。
4. 停止生成：流式中点停止，内容保留、发送键复位。
5. `file://`：双击 `index.html`，确认不发起任何网络请求、状态显示“本地演示（file://）”。
6. 减少动效：系统开启“减弱动态效果”后首次打开即为安静模式。

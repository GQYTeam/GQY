# 029 · 人格与头像

日期：2026-11-02
状态：完成

## 目标

让本地助手有可编辑的名称、一句话介绍、头像与系统提示词；配置落在本机，进入对话时作为 system 消息注入模型。

## 范围

**做：**

- `$GQY_HOME/persona.json`：`name`、`tagline`、`avatar`（data:image/*，≤768 KB）、`system_prompt`（≤8000 字节）。
- `GET|PUT /api/persona`；缺失/损坏回退默认 `GQY / 本地优先的 AI 助手网关`。
- `/api/chat` 在消息最前面注入 system 提示词（已有 system 消息时不重复）。
- WebUI：品牌头像/名称、助手消息头像与名称、控制台「人格」面板（名称/介绍/头像/系统提示词）。
- 头像只在服务端持久化，不进 localStorage；读接口返回本人格数据。

**不做：**

- 多人格库、人格切换、人格市场（参考 WebUI 的完整 persona 体系，后置）。
- 头像裁剪、图片压缩、CDN。
- 语音 / 人设情绪。

## 验收

- `PUT /api/persona` 保存后 `GET` 返回一致；非法头像/超长字段 400。
- 设置系统提示词后，fake 上游收到的第一条消息角色为 system。
- 控制台人格面板保存后头像、名称立即反映到品牌与助手消息。
- `go test ./internal/persona ./internal/httpapi`、`make ui-smoke` 通过。

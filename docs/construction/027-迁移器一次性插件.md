# 027 · 迁移器一次性插件

日期：2026-11-02
状态：施工中

## 目标

把旧版 GQY v0.7.0 的真实 `GQY_HOME` 导出（`gqy_backup_20261005_180648`，397 MB）迁到新版数据根，做成**一次性插件**：跑一次、跑完即弃、不常驻，用现成的 `gqy run` 内核执行；迁完记忆立即可用。

依据：`18-记忆与迁移.md` MG1–MG8；`15-一次性插件.md` NX1–NX7；`blueprint/migrate.md`。

## 范围

**做：**

- 新仓库 `GQYTeam/gqy-plugins-Migrator-default`：Node ≥22.5 零依赖，`node:sqlite` 只读旧库。
- `run` 动作 + 参数：`input` / `home` / `apply` / `kinds` / `persona` / `include_secrets` / `no_backup` / `report`。
- 迁移组：config / personas（人格清单）/ memory（facts、episodes、revisions、evicted、embeddings、pending_events、skill_records）/ kb / prompts / memes / skills / scripts / identities / usage / archive。
- 报告：计数、跳过原因、孤儿向量、脱敏项数、耗时、退出码；只含结构不含正文。
- 幂等：`legacy_id` 差集 + `source_fingerprint`。
- 安全：只读源、默认 dry-run、默认脱敏、覆盖前备份、拒绝符号链接。
- 仓库标准基线（LICENSE/NOTICE/CI/Issue/PR/CHANGELOG/Makefile/…），公开仓库与 CI 绿。
- 端到端：用真实备份 dry-run → apply 到临时 home → 起 `gqy-server` 验证 `/api/memory` 与召回 → 再跑一次验证幂等。

**不做（后置）：**

- 会话正文完整迁移：`conversation.db` 195 MB 只做 best-effort（sessions + turns 文本），journal 事件与 redo 备份不迁。
- 图片 / 文档 / 账本 / 平台消息默认不复制，属 `archive` 组显式开启。
- 旧版 `suggest` 动作与训练管线：已被 015 留底判定不达标并回滚，不迁。
- 一次性插件的 HTTP 路由与控制台入口：本次只走 `gqy run` CLI，宿主接线另开施工单。

## 关键决定

- **迁移不写进常驻二进制**：一次性插件形态，跑完清理；常驻服务不背迁移配置与代码。
- **先计划后执行**：默认 dry-run，报告就是「迁移计划」；`--apply` 才落盘。
- **能力降级要显式**：旧配置里的 `api_key` / 平台 token 默认不迁，写 `api_key_env` 引用；旧库掉队的孤儿向量计入报告而不是静默丢弃。
- **大媒体默认不动**：397 MB 里的图片与数据库占 96%，默认只报体积，避免把旧数据再复制一份。
- **报告即证据**：每次运行落 `.migrate-reports/<run>.json`，两次运行可对比，迁移可复现。

## 验收

```bash
# dry-run：报告计数与源库一致
gqy run ./gqy-plugins-Migrator-default --args '{"input":"<backup>"}'

# apply 到临时 home
GQY_HOME=/tmp/gqy-home gqy run ./gqy-plugins-Migrator-default --args '{"input":"<backup>","apply":true}'

# 记忆可用
curl -s localhost:5173/api/memory
curl -s -X POST localhost:5173/api/memory/default/recall -d '{"query":"<关键词>","limit":5}'

# 幂等 + 脱敏
# 二次 apply 的 records_added = 0；目标里 grep 不到明文密钥

# 仓库标准
cd gqy-plugins-Migrator-default && npm test && make check
```

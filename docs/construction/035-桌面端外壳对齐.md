# 035 · 桌面端外壳对齐

状态：完成（2026-11-02）

## 目标

把 `dist/GQY.app` 的 macOS 外壳对齐 `miyu-desktop` 的行为：单实例、窗口状态、关窗藏起、托盘、彻底退出、导航、下载、应用菜单、日志。做完这一单，app 是一个双击即用、关窗不退出、托盘能叫回、退出会停服务的常规 macOS 应用。

## 范围

**做（对齐 `miyu-desktop` 的 `docs/blueprint/desktop.md` 第 1–15 条）：**

- 单实例：第二次启动把已有窗口拿到最前，自己退出。
- 窗口状态：记住大小、位置、最大化；首次 75% 屏、≥1100×760、≤90%、居中。
- 关窗口只藏起，Go 服务与页面照旧活着；点 Dock 图标（Reopen）把窗口拿回来。
- 托盘：模板图标，菜单「显示 GQY」「退出 GQY」；左键显示窗口，右键出菜单。
- 彻底退出（托盘 / ⌘Q / 应用菜单）：先藏窗口、拿掉托盘，再停 Go 服务，最后退出；系统关机/注销只退外壳。
- 导航：同来源（同协议、同主机、同端口）放行；`about:`、`blob:`、`data:` 放行；`http`、`https`、`mailto` 交系统浏览器；其他协议不开；新窗口一律交系统浏览器。
- 下载：存「下载」目录，重名加「 (1)」「 (2)」，没有名字的叫 `download`。
- 应用菜单：退出 GQY、编辑（撤销/重做/剪切/复制/粘贴/全选）、窗口（最小化、关闭窗口 ⌘W 即藏起）、显示（重新载入 ⌘R）。
- 日志：外壳一行一条写 `~/Library/Logs/GQY/desktop.log`，只记启动、服务状态、错误、退出；不记带票网址。
- 启动失败：系统对话框，「重试」「退出」；「退出」只退外壳。
- 配合退出：进程收到退出信号时先关掉 SSE 长连接，Go 服务能在 10 秒内优雅退出；不关的话 `http.Server.Shutdown` 会等到超时再被强杀。

**不做（留到后续施工单）：**

- 网页通知权限（WKWebView 没有 Web Notification，按 Miyu DT-3 的办法另定）。
- dmg 打包、签名、自动更新（039）。
- 网页 UI 的版式与视觉重做（036–037）。
- Go 服务的接口改动。

## 落点

- `desktop/macos/main.swift`：入口、单实例锁、应用委托。
- `desktop/macos/InstanceLock.swift`：单实例锁、叫已有窗口。
- `desktop/macos/Server.swift`：Go 服务生命周期、健康检查、日志。
- `desktop/macos/Shell.swift`：窗口、托盘、菜单、导航、下载、退出。
- `scripts/build-macapp.sh`：编译全部 Swift 源文件。
- `app/internal/httpapi/events.go`、`app/cmd/gqy-server/main.go`：退出时关 SSE 长连接，优雅关闭不再等满 10 秒。
- `app/internal/httpapi/events_test.go`：关连接与关后重新订阅的测试。
- `docs/designs/21-与Miyu对齐.md`、本文件、索引与 README 的状态更新。

## 验收

1. `make macapp` 成功，产出 `dist/GQY.app`。
2. 双击打开：窗口出现，`/healthz` 返回 200，页面加载。
3. 关窗口：进程仍在，Go 服务仍在监听；点 Dock 图标窗口回来。
4. 托盘左键：窗口拿到最前；右键：菜单出现，点「显示 GQY」窗口回来。
5. 「退出 GQY」/⌘Q：Go 服务退出（端口不再监听），app 退出。
6. 第二次启动：不新起服务，已有窗口到最前。
7. 页面里的外链：用系统默认浏览器打开，不在 app 内导航。
8. 页面触发的下载：文件落在 `~/Downloads`，重名加编号。
9. `make check` 通过；`make macapp` 编译无警告（Swift 允许的弃用除外）。

## 留底

2026-11-02 完成，实测：

- `make macapp` 成功，`dist/GQY.app` 19M。
- 双击启动后 `/healthz` 返回 200，首页 200；`~/Library/Logs/GQY/desktop.log` 记下 `launch`、`loading page`。
- 第二次 `open`：app 与 Go 服务各保持 1 个进程，没有新起服务。
- 关闭窗口的行为按 `windowShouldClose` 藏起；Dock 图标与托盘「显示 GQY」走同一个 `showWindow`。
- ⌘Q（AppleScript `quit` 同路径）：`desktop.log` 记 `quit requested`，Go 服务同一秒退出，端口关闭；`server.log` 显示 `收到退出信号` 后 SSE 请求正常结束。
- 外链、下载走 `WKNavigationDelegate` / `WKDownloadDelegate`，编译通过；手测外链与下载尚未做（需要页面触发，下一步在 UI 验收里补）。
- 偏差：托盘图标用系统符号 `sparkles`（模板图），不是 GQY 头像的模板化版本；通知权限按计划后置；`windowShouldClose` 的藏起行为未在无辅助功能权限的机器上自动化手测。

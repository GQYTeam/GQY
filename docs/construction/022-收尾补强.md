# 022 · 收尾补强

日期：2026-11-02
状态：完成

## 目标

补掉 020 留底里的两个尾巴：工具产物路径（`artifact_paths` 恒为空）与流式空闲超时；并做一次仓库卫生检查。

## 范围

**做：**

- `settings.stream_idle_timeout_s`（默认 60，范围 5–600）：流式调用连续无新事件即中止，归一为 `upstream_timeout`（可重试、504）。
- `tool.Record.Artifacts`：写文件类工具（当前 `edit`）返回产物路径；`tool` 事件与工具日志都带 `artifact_paths`。
- 仓库卫生：ShowImages 插件仓补 `.gitignore`；清理根目录 stray 二进制；确认构建产物均在 ignore 内。
- 测试：流式空闲超时（5s 生效、错误码与可重试）、`artifactsFor` 规则、工具日志写入产物路径。

**不做：**

- `write_artifact` 工具（后续施工单）。
- 产物自动登记进会话 manifest（当前只记事件与日志）。

## 关键决定

- **空闲超时与整体超时并存**：整体超时防「一直慢慢流」，空闲超时防「发一帧就卡住」。
- **产物在 agent 层推断**：工具接口保持 `(string, error)`，`artifactsFor(name, args)` 集中登记哪些工具写文件，避免改工具接口。
- **产物路径原样记录**：不脱敏（路径本身不是密钥），但摘要仍过 `RedactText`。

## 验收

```bash
make check
cd app && go test -race ./...
```

行为验收：

1. 流式上游发一帧后卡住：`stream_idle_timeout_s` 到期返回 `upstream_timeout`，不无限挂起。
2. `edit` 成功调用后，`tool` 事件与 `logs/tools/*.jsonl` 都含 `artifact_paths`。
3. `read` 等非写文件工具不产生 `artifact_paths`。
4. ShowImages 插件仓有 `.gitignore`，仓库内无构建产物。

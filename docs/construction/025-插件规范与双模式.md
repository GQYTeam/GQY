# 025 · 插件规范与双模式

日期：2026-11-02
状态：完成

## 目标

把插件接入 WebUI 所需的「设置按钮 / 可配置 / 删除」做齐，并把插件来源分成 **在线安装（只读）** 与 **本地自建（开发模式，可改）**；同时用测试把组织内所有插件仓库的 manifest 规范钉死，不能钉死的部分写进可发现的文档。

## 范围

**做：**

- manifest 增 `source`（installed/local，由 `.gqy-installed` 标记派生）与 `settings` schema（string/number/boolean/select）。
- `PluginStatus` 暴露 `source` / `read_only` / `settings` / `has_settings`。
- 设置存储：`$GQY_HOME/plugin-settings/<id>.json`（0600，原子写），与插件目录分离；`ValidateSettingValues` 严格校验。
- API：`GET|PUT /api/plugins/{id}/settings`、`DELETE /api/plugins/{id}`（卸载→删目录→删设置，拒绝路径穿越）。
- WebUI 插件页：模式徽标、设置按钮 + schema 表单（四种控件）、保存、删除（二次确认）。
- 强制校验：`TestPluginReposConform` 校验 GQY 内置插件 + 同级 `gqy-plugins-*` 仓库 manifest。
- 文档：`docs/reference/plugin-manifest.md`（唯一规范）、设计 17（PL1–PL8）、org `STANDARDS.md` 新增插件规范章节。

**不做：**

- 插件本体在线编辑（开发模式也只改文件）。
- 安装器与在线目录（`gqy-plugins` 路线图）。
- 设置项加密。

## 关键决定

- **设置与本体分离**：安装版插件只读，但设置写到独立目录，因此「可配置」与「不能改本体」不冲突。
- **来源由标记文件派生**：源码仓库不可能误带 `.gqy-installed`（测试会抓），安装目录才写标记。
- **删除统一**：两种模式都可删除；只读只约束「改」，不约束「删」。
- **能强制就强制**：manifest 规范进测试和 CI；文件系统之外的行为写进文档通告。

## 验收

```bash
make check
cd app && go test -race ./...
node --check app/js/*.js
```

行为验收：

1. 无标记目录 → `source=local`、`read_only=false`；有标记 → `installed`、`read_only=true`。
2. `GET /api/plugins/{id}/settings` 返回 schema/values/effective/source/read_only。
3. `PUT` 合法值保存并影响 effective；未知键、类型不符、select 越界被拒；`null` 恢复默认。
4. `DELETE /api/plugins/{id}` 卸载 + 删目录 + 删设置；重复删除 404；`..` 被拒。
5. WebUI：模式徽标、设置表单四类控件、保存、删除二次确认。
6. `TestPluginReposConform` 对内置插件与同级插件仓库全部通过；源码仓库带安装标记会红。

## 留底

完成（2026-11-02）。`gofmt`/`vet`/`go test ./...`（14 包 0 失败）/`make check` 全绿；`node --check` 全过。

测试：`TestPluginSourceDerivation`（local/installed 判定）、`TestSettingsSaveAndEffective`（默认合并、合法保存、未知键/类型/选项拒绝、null 回落、0600 权限）、`TestPluginDelete`（卸载、删目录与设置、重复删除 404、`..` 拒绝）、`TestPluginReposConform`（内置 2 个 + 同级 3 个仓库 manifest 校验）。

实测（真实运行，`app/plugins/echo` 复制进临时 `$GQY_HOME/plugins/echo`）：

- `GET /api/plugins` → `source=local`、`read_only=false`、`has_settings=true`；
- 默认调用 `echo` → `echo:hello`；`PUT settings {"prefix":"X:","uppercase":true}` → 卸载→加载后再调用 → `X:HELLO`（设置经 `initialize` 下发）；
- 卸载后列表显示 `state=discovered`（仍可见、可再加载）；
- `DELETE` → 插件目录、`<id>.log`、设置文件全部清空，列表为空。

已修：卸载原先会把实例从表里摘除（导致「卸载后无法再加载/删除」），改为回到 `discovered`；`Delete` 额外清理 `<id>.log`。

偏差：

- WebUI 只做了 DOM 接线与 `node --check`，未做浏览器端点击回归（需要你打开页面点一次）。
- 安装器（写 `.gqy-installed`）未实现，目前只有语义与校验；等 `gqy-plugins` CLI。
- 「别人在本地改插件」只能靠标记 + 只读语义 + 文档约束，无法代码禁止；已写入 org STANDARDS 通告。

## 施工单模板

1. **目标**：这一单交付什么可运行、可验收的能力。
2. **范围**：做 / 不做，引用设计文档的决定编号。
3. **落点**：新增或修改的文件。
4. **验收**：可直接执行的命令与断言。
5. **留底**：完成后补一句实际结果与偏差。

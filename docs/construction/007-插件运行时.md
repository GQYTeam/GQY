# 007 · 插件运行时

日期：2026-11-02
状态：进行中

## 目标

把插件运行时四层接成可用：业务层只认「调用(插件ID, 动作, 参数)」，运行时层管生命周期、并发、超时、回收与可观测，注册中心层选适配器，适配器层支持原生 stdio 换行 JSON-RPC、MCP stdio、unix / tcp 三种协议；动作注册成外部工具交给 006 的工具注册表，并提供 `/api/plugins*` 管理接口。

## 范围

**做：**

- 插件运行时四层：业务层 / 运行时层 / 注册中心层 / 适配器层（P1）。
- 三种适配器：原生 stdio 换行 JSON-RPC（`gqy-jsonrpc-v1`）、MCP stdio（`mcp`）、unix / tcp 远程（P4）。
- 生命周期状态机（discovered → loading → ready → closing → closed，外加 failed）与进程回收时序（P5 / P8）。
- 并发模型：concurrent / single-channel / exclusive，适配器声明、运行时放行（P6）。
- 调用超时与取消传播（P7）。
- 热更新：安装 / 卸载 / 重装，全部幂等（P9）。
- provides / requires 前置检查：缺依赖拒载、有依赖拒卸载、环拒载（P10）。
- 插件动作注册成外部工具，消费方为 006 的工具注册表（P11）。
- `/api/plugins*` 状态与调试调用（P12）。

**不做（后续施工单 / 后置）：**

- 插件市场、自动级联加载、权限审批流。
- 动态加载 Go `.so` / WASM 插件。
- 远程 gRPC 适配器、TLS 认证。
- 自动重启、熔断、心跳、流式调用、事件订阅。
- 按插件的运行时权限墙（SEC5：安装即信任）。

## 关键决定

- **P1**：业务层只认「调用(插件ID, 动作, 参数) → (内容, 错误)」；错误只出 `not_found` / `not_ready` / `timeout` / `invalid_argument` / `call_failed` / `exited` / `canceled`；核心层不出现社区专有字段。
- **P2**：注册中心三级选择：显式指定 → 社区名匹配 → 探测；命中多个适配器直接报错，不用注册顺序兜底。
- **P3**：manifest 全字段照 `blueprint/plugin.md`；id / version / protocol / command / cwd / env / timeout_ms / concurrency / actions / address / provides / requires 各自校验，未知字段忽略，校验失败整体拒绝。
- **P4**：三种适配器都只实现「识别 / 加载 / 调用 / 关闭」；原生与 MCP 拉起进程，unix / tcp 只连接不拉起、绝不杀远程进程。
- **P5**：生命周期状态机 + 加载失败回滚；Load / Unload 幂等；崩溃置 `failed` 不自动重启。
- **P6**：并发模型按 manifest 声明放行；stdio 用「请求序号 → 等待通道」多路复用，错序不串包。
- **P7**：每次调用带 deadline（上限 `timeout_ms`）；晚到结果丢弃；进程级中断归 P8。
- **P8**：进程回收固定时序：closing 拒新调用 → 等在途（上限 5s）→ 关 stdin（EOF 自退）→ 等 5s → SIGTERM → 等 2s → SIGKILL → 回收；独立进程组整组杀，无孤儿。
- **P9**：热更新全幂等；重扫不重启运行中实例，仅 manifest 变化（id / version / protocol / 入口 / 依赖）触发重载。
- **P10**：服务表 = 核心内置服务 + 已就绪插件 `provides`；缺依赖拒载、有依赖拒卸载、环拒载；不自动级联加载。
- **P11**：动作注册成外部工具 `pluginID__action`（非字母数字转 `_`，最长 64）；卸载注销；命名冲突回滚加载；默认不注入，`GQY_ENABLE_EXTERNAL=1` 才进工具列表，`/api/plugins/{id}/call` 始终可调试。
- **P12**：`GET /api/plugins` 暴露状态 / 协议 / pid / 调用数 / 失败数 / 最近错误；孤儿兜底触发恒为 0，非零告警。

## 落点

```
app/internal/plugin/{plugin,native,mcp,remote,transport,proc_unix,proc_windows,tool}.go
app/internal/httpapi/plugins.go      # /api/plugins* 管理接口
app/plugins/echo/{index.js,manifest.json}
app/plugins/mcp-echo/{index.js,manifest.json}
```

- 插件目录运行时位置：`$GQY_HOME/plugins/<id>/manifest.json`；stderr 日志 `$GQY_HOME/plugins/<id>.log`。
- 006 的工具注册表消费 P11 产出的外部工具名与 schema。

## 验收

```bash
make check
cd app && go test -race ./...
```

行为验收（契约测试）：

1. manifest：重复 id 报错、非法 id 拒绝、未知 `protocol` 无适配器匹配并报错。
2. 原生：加载 → `initialize` → `call` → `shutdown` → 卸载全链路；结果与错误翻译正确。
3. MCP：`initialize` → `tools/list` 发现动作 → `tools/call` 调用；`isError` 映射 `call_failed`。
4. 远程：unix / tcp 加载成功且全程不拉起进程；断开后实例置 `failed`；不杀远程进程。
5. 生命周期：加载失败回滚无残留；卸载幂等；closing 拒新调用；崩溃置 `failed` 不无限重启。
6. 并发：10 个并发调用不串包，响应按请求 id 一一对应；`exclusive` 串行可断言。
7. 超时：插件 sleep 超过 `timeout_ms` 返回 `timeout`；卡死进程被回收；晚到结果丢弃。
8. 进程回收：stdin EOF 自退；SIGTERM 未退升级 SIGKILL；父进程异常退出后插件限时自退，无孤儿。
9. 依赖：缺依赖拒载；有依赖拒卸载；环拒载。
10. 工具注入：开关开启才注入、关闭即移除；命名冲突回滚加载。
11. 热更新：安装 → 扫描 → 加载；重装先卸载旧实例；重扫不重启运行中实例。
12. `/api/plugins` 状态字段完整；调试调用返回 `{ok, content|error}` 形状。

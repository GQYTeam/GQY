# 034 · 应用图标（macOS + Web）

日期：2026-11-02
状态：完成

## 目标

从一张人物图**用代码完整产出** GQY 的 macOS 应用图标：`.icns`、Xcode `appiconset`、母版、Web 图标与预览图；可重复生成，不手改位图。

## 范围

**做：**

- `scripts/make-icon.py`：读取方图 → 按 macOS Big Sur+ 网格（1024 画布、824 内容、圆角 185、透明外圈）生成圆角母版 → 导出 10 个尺寸、`AppIcon.icns`（`iconutil`）、`AppIcon.appiconset`（含 `Contents.json`）、`favicon-32` / `apple-touch-icon`、`preview.png`。
- **小尺寸面部聚焦**：≤64px 使用上半身裁切版，避免整身像在小尺寸糊成一团；可用 `--no-small-focus` 关闭，并生成 `preview-small.png` 像素级对比。
- 极细内描边（白色 18% alpha），避免浅色插画与浅色桌面糊边。
- `assets/icons/`：产出物 + 源图 + `README.md`（尺寸表、设计规则、重新生成、放进 `.app` 的方法）。
- `make icon`：一条命令重新生成。

**不做：**

- 不改 Web 前端的 favicon（仍是 `app/assets/icon.svg` 品牌字标）；如需统一切换，README 里给了两步做法。
- 不生成 `.app` 包体（只交付图标资产与 Info.plist 片段）。

## 关键决定

- **代码生成而非手工切图**：尺寸、圆角、内边距都可复算，换源图只需重跑。
- **两套母版**：1024 用完整构图；≤64 用面部聚焦，兼顾「大图有氛围、小图能认出」。
- **保留源图**：`assets/icons/source.jpg` 入库，保证任何人 `make icon` 都能复现。
- **Web 与应用图标分离**：应用外壳用头像图标，网页 favicon 保持字标，避免品牌混用。

## 落点

```
scripts/make-icon.py
assets/icons/               # 产出物 + source.jpg + README
Makefile                    # make icon
```

## 验收

```bash
make icon
file assets/icons/AppIcon.icns
for f in assets/icons/AppIcon.iconset/*.png; do sips -g pixelWidth "$f"; done
iconutil -c iconset assets/icons/AppIcon.icns -o /tmp/check.iconset   # 可反向解包
```

行为验收：

1. 10 个尺寸像素正确（16/32/64/128/256/512 及 @2x），`.icns` 可被 `iconutil` 反向解包出同样 10 个尺寸。
2. 母版 1024：内容 824、四边 100、圆角 185、外圈透明。
3. `AppIcon.appiconset/Contents.json` 的 `images` 与文件一一对应（mac idiom）。
4. `preview.png` 浅/深底可读；`preview-small.png` 能看出聚焦版更清晰。
5. `make icon` 幂等：重复运行不产生额外文件、不改动其他资产。

## 留底

完成（2026-11-02）。产出：

- `assets/icons/AppIcon.icns`（1.5 MB，`iconutil` 反向解包得到全部 10 个尺寸）。
- `AppIcon.iconset/` 10 个 PNG，`sips` 核对像素：16/32/32/64/128/256/256/512/512/1024 全部正确。
- `AppIcon.appiconset/` 10 个 PNG + `Contents.json`（idiom=mac、scale 1x/2x、size 配对）。
- `icon-1024.png`（透明圆角母版）、`icon-small-focus-1024.png`（小尺寸母版）。
- `favicon-32.png`（32×32 RGBA）、`apple-touch-icon.png`（180×180 不透明）。
- `preview.png`（1024 按 50% + 512/256/128/64/32/16，浅底/深底两行）、`preview-small.png`（16/32/64 原生 vs 聚焦，像素放大对比）。
- `make icon` 可用（`PYTHON=...` 可指定带 Pillow 的解释器）；`assets/icons/README.md` 写清尺寸表、设计规则与 `.app` 接入方式。

设计取舍：1024 用完整构图（含裙摆氛围），≤64 换面部聚焦版——预览对比里小尺寸可读性明显更好。

偏差：未生成 `.app` 包体与 Windows `.ico`（如需要，下一步加 `--ico` 与打包脚本）。

# 030 · 动态热加载

日期：2026-11-02
状态：完成

## 目标

让「开关插件」「改配置」「换模型」都不需要重启：插件增删立即改变模型可见的工具表；配置文件改动自动热加载；暴露策略可热切换；全程不打断在途请求。

## 范围

**做：**

- 配置轮询热加载：`providers.json` / `routing.json` / `settings.json` 的 mtime+size 变化 → `Reload()`；非法配置保留旧快照。
- 配置订阅：`Manager.Subscribe(fn)`，快照切换后锁外回调。
- 插件变更钩子：`Manager.SetOnChange(fn)`，Scan / Load / Unload / Delete 后触发。
- 工具表热重建：`Registry.ResetExternal()` 按 `Owned` 接口只清插件工具；服务端 `RefreshTools()` 重建。
- 暴露策略：`settings.expose_external_tools`（默认 true，热更新）；manifest `expose:false` 单插件隐藏；`/api/tools` 增 `exposed`。
- `agent.ToolInfo.Exposed` 供 UI/运维判断模型可见性。
- 测试：配置监听（改动生效、非法保留旧快照）、插件钩子、`ResetExternal` 只清插件工具、暴露开关决定 core/external 注册。

**不做：**

- 插件进程内代码热替换（改代码走 卸载→加载）。
- fsnotify/inotify（轮询 2s，零依赖）。
- 在途 loop 中途换模型。

## 关键决定

- **插件变化 = 工具表变化**：把「加载插件」和「模型能看见」绑成同一件事，不再靠重启或手改 env。
- **只清自己的东西**：`Owned` 接口让重建精确到插件工具，核心工具永不因热更新丢失。
- **订阅回调放锁外**：避免回调里读快照或做重活导致死锁。
- **配置写坏不回退版本**：保留旧快照，`config.version` 不变，等修好再切。

## 验收

```bash
make check
cd app && go test -race ./...
```

行为验收：

1. `POST /api/plugins/{id}/load` 后 `/api/tools` 立即出现该插件工具且 `exposed=true`，无需重启。
2. `unload` / `DELETE` 后工具立即消失。
3. 改 `settings.json` 的 `expose_external_tools`，2–3s 内 `/api/tools` 的 `exposed` 翻转，无需重启。
4. 改 `providers.json` 增加 provider，`config.version` 自增、模型可用；写坏配置时版本不变、旧配置继续服务。
5. `manifest` 里 `expose:false` 的插件动作不进模型工具表，但仍可经 `/api/plugins/{id}/call` 调用。
6. 全程不需要重启进程，在途无常驻状态被清。

## 留底

完成（2026-11-02）。`gofmt`/`vet`/`go test ./...`（15 包 0 失败）/`make check` 全绿。

测试：`TestWatchReloadsOnFileChange`（20ms 轮询下改 providers.json 生效、非法配置保留旧快照）、`TestPluginChangeHookFires`（Scan/Load/Unload/Delete 各触发回调）、`TestResetExternalRemovesOnlyPluginTools`（只清插件工具）、`TestRegisterToolsExpose`（暴露→core、关闭→external、命名 `<plugin>__<action>`）。

真实运行（echo 插件、真进程、不重启）：

- load 后 `/api/tools` 中 `echo__echo` 出现且 `exposed=true`；
- 卸载后消失；
- 改 `settings.json` → `expose_external_tools:false`，3s 内 `exposed=false`（插件仍可经 `/api/plugins/echo/call` 调用）；
- 改回 true，`exposed` 恢复 true；
- `DELETE` 后工具表清空；
- `config.version` 随配置热加载自增。

偏差：

- 「选模型」本就是每请求解析（HR5），未新增服务端全局默认模型切换接口；如果要做「一次选择、全局生效」，需要新增 `routing.json` 的运行时覆盖接口，另开施工单。
- 配置轮询 2s 固定，未做成可配置项。

# 032 · 全局模型与实时推送

日期：2026-11-02
状态：完成

## 目标

两件事：**选一次模型，全局生效**（内部 loop 与外部 agent 都走它，可持久化）；**用持久连接把变更实时推给客户端**，替代前端轮询。

## 范围

**做：**

- `GET /api/model/active`、`PUT /api/model/active {model, persist?}`：校验模型可解析 → 设置运行时覆盖；`persist:true` 原子写 `routing.json` 的 `default` 并热加载。
- 网关 `SetActiveModel/ActiveModel`：`resolveOrdered` 在请求未指定 model 时优先用覆盖，显式 model 优先，空覆盖回落配置默认。
- SSE 长连接 `GET /api/events`：事件 `ready` / `config` / `plugins` / `model`，15s 心跳，慢客户端丢弃。
- 发布点：配置订阅（version）、插件变更钩子、全局模型切换。
- 前端：`api.events()`（EventSource）+ `initLiveUpdates()`，收到 `config`/`model` 刷新模型与状态、`plugins` 刷新插件页；`store.liveStream` 保持单连接。
- 配置轮询默认 1s（`GQY_CONFIG_POLL_MS` 可调，最小 100ms）。

**不做：**

- 推送权限细分（沿用 `/api/*` 鉴权）。
- 多实例广播（单机网关；多实例需消息总线，后置）。
- WebSocket（SSE 单向足够）。

## 关键决定

- **覆盖在网关层解析**：所有协议入口天然受益，不用在每个 handler 里复制逻辑。
- **持久化只写 provider/model**：路由组不落 `default`，避免把策略写死成单模型。
- **SSE 单连接 + 事件类型**：前端只维护一条连接；事件带 `ts`，便于排障。
- **慢客户端丢弃**：广播不阻塞发布方，避免一个卡死的浏览器拖垮服务。

## 落点

```
app/internal/gateway/router.go              # SetActiveModel/ActiveModel/ResolveModel + resolveOrdered
app/internal/httpapi/model.go               # GET/PUT + routing.json 持久化
app/internal/httpapi/events.go              # SSE hub + handleEvents
app/internal/httpapi/server.go              # 路由与 events 初始化
app/cmd/gqy-server/main.go                  # 发布点 + 1s 轮询/环境变量
app/js/{api.js, app.js, settings.js, store.js}
```

## 验收

```bash
make check
cd app && go test -race ./...
node --check app/js/*.js
```

行为验收：

1. `PUT /api/model/active {"model":"p/m2"}` → 之后未指定 model 的请求走 p/m2；显式 model 仍优先。
2. `persist:true` → `routing.json` 的 `default` 更新且配置版本自增，重启后仍生效。
3. 非法模型 400 `model_not_found`；空 model 清除覆盖并回落配置默认。
4. `GET /api/events` 建立后收到 `ready`；触发配置/插件/模型变化时收到对应事件。
5. 改 `settings.json` 后 ≤1.5s 内 `config_version` 自增。
6. WebUI 保持单条 SSE 连接，收到事件即时刷新模型/插件列表。

## 留底

完成（2026-11-02）。`gofmt`/`vet`/全仓测试/`make check`/`node --check` 全绿。

测试：`TestActiveModelOverride`（空 model 走覆盖、显式优先、清除回落）、`TestActiveModelEndpoints`（初始 config、非法 400、切换 runtime、persist 写回 routing.json 且版本自增、清除回落）、`TestEventsStreamPushes`（ready + model 事件经 SSE 送达）。

真实运行（不重启）：

- 初始 `{"model":"p/m1","source":"config"}`；
- `PUT {"model":"p/m2","persist":true}` → `{"persisted":true}`，`routing.json.default` 变为 `p/m2`；
- 非法模型 → 400；
- 后台 `curl -N /api/events` 期间切换模型 → 收到 `ready` / `model` / `config` 事件；
- 改 `settings.json` → 2s 内 `config_version` 自增。

偏差：多实例广播未做（单机网关假设）；SSE 事件不带版本号，重连后客户端全量刷新。

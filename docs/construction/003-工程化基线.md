# 003 · 工程化基线

日期：2026-11-02
状态：完成

## 目标

把仓库从「能跑」提升到「可协作、可发布」：一条命令跑完格式/静态检查/测试/构建，CI 在 Go 1.22 与 stable 上全绿，tag 推送自动出多平台发布包。这是 002 留底里后置的部分。

## 范围

**做：**

- 根目录 `Makefile`：`check`（fmt + vet + test + build）、`race`、`cover`、`lint`、`run`、`tidy`、`clean`。
- `.github/workflows/ci.yml`：Go 1.22.x + stable 矩阵；gofmt 检查、`go vet`、`go test -race -coverprofile`；覆盖率产物上传。
- `.github/workflows/codeql.yml`：CodeQL 扫描。
- `.github/workflows/release.yml` + `.goreleaser.yaml`：tag `v*` 触发 GoReleaser，darwin/linux/windows × amd64/arm64，tar.gz/zip，checksum，版本信息注入 `internal/buildinfo`。
- `.golangci.yml`：errcheck/staticcheck/govet/gosec 等一组 linter，测试文件放宽 errcheck/gosec。
- `.github/dependabot.yml`、Issue 模板（bug/feature）、PR 模板。
- 根 `CONTRIBUTING.md`、`SECURITY.md`、`CHANGELOG.md`、`.editorconfig`。

**不做（后续施工单）：**

- Anthropic Messages / Gemini 适配器（004）。
- 会话、工具、插件、评测、前端等业务能力。
- 签名公证、Homebrew 包、Docker 镜像（按需再开）。

## 关键决定

- **构建产物只进 `app/bin/`**，根目录不落二进制；`app/gqy-server` 已加入 `.gitignore`。
- **CI 不依赖外部服务**：gofmt / vet / test 全本地可跑；lint 与 release 由对应 action 提供工具。
- **版本信息走 ldflags 注入**（`gqy/internal/buildinfo`），goreleaser 与 Makefile 共用同一组变量名。
- **CodeQL 与 CI 分开**，不阻塞普通 PR 的快速反馈。

# 009 · 一次性插件

日期：2026-11-02
状态：进行中

## 目标

把 007 的插件运行时扩展出「一次性」执行模式：`gqy run <来源>` 按四级来源（本地路径 / git / url / 内置注册表）拉取插件到临时目录、校验哈希、执行（`run` 动作或直接 `command`）、收集产物、默认清理，可选 `--keep` 保留；同版本执行走 7 天 TTL 缓存，交给 `gqy-clean --expired` 回收。一次性插件不注册工具、不占常驻实例表。

## 范围

**做：**

- `gqy run <来源>` CLI：NX2 四级来源解析。
- 拉取到 `$GQY_HOME/tmp/oneshot/<id>-<run>/`，校验 manifest 与哈希（NX2）。
- 执行：声明 `run` 动作走 stdio JSON-RPC `call`，未声明直接跑 `command`（NX3）。
- 产物收集三形状：stdout / 结构化结果 / 声明文件（NX4）。
- 默认删除工作目录，`--keep` 保留（NX4）。
- 缓存键 `<id>-<version>` + 哈希，TTL 7 天，`gqy-clean --expired` 回收（NX6）。
- 安全：来源显式指定，哈希存在则强校验，缺哈希告警后执行（NX7）。

**不做（后续施工单 / 后置）：**

- 插件市场与自动发现。
- 代码签名 / 供应链证明。
- daemon 化的一次性任务。
- 跨运行状态保持。
- 一次性插件的细粒度权限 / 断网沙箱（SEC5：执行即信任）。

## 关键决定

- **NX1**：一次性插件是执行模式不是新格式；manifest 同 04 P3，加 `mode:"oneshot"`，缺省 `resident`。
- **NX2**：来源四级（本地路径 / git / url / 内置注册表），拉到 `$GQY_HOME/tmp/oneshot/<id>-<run>`；校验 manifest 与哈希，失败即弃。
- **NX3**：声明 `run` 动作走 stdio JSON-RPC `call`（`action:"run"`），未声明直接跑 `command`；进程托管复用 007 的 proc 回收（P8）。
- **NX4**：生命周期固定「解析 → 拉取 → 校验 → 执行 → 收集产物 → 默认删工作目录」；`--keep` 保留；失败同样清理，退出码非 0 不进缓存。
- **NX5**：不注册工具、不走 P11 动作注册、不占常驻实例表；执行完不占用。
- **NX6**：缓存键 `<id>-<version>`，命中要求哈希一致；TTL 7 天，由 `gqy-clean --expired` 回收（ST7）。
- **NX7**：沿用 SEC5 执行即信任；来源显式指定、哈希强校验防篡改，缺哈希告警后执行；不额外断网 / 沙盒。

## 落点

```
app/cmd/gqy-run/main.go                 # 或 gqy-server 子命令（施工单定）
app/internal/oneshot/{resolve,pull,run,collect,cache}.go
app/internal/plugin/{native,mcp,transport,proc_unix,proc_windows}.go   # 复用 007
app/internal/storage/cleanup.go         # 增量：oneshot 缓存 TTL
```

- 复用 007 的插件适配器（native / mcp）与进程回收；oneshot 只做来源解析、拉取、缓存与产物收集。
- 拉取目录 `$GQY_HOME/tmp/oneshot/<id>-<run>/`，缓存 `$GQY_HOME/tmp/oneshot/.cache/<id>-<version>/`（形状见 `blueprint/oneshot.md`）。

## 验收

```bash
make check
cd app && go test -race ./...
```

行为验收：

1. `gqy run <本地路径>` 直接执行并清理；`gqy run <git|url|reg>` 按格式解析并拉取。
2. 哈希不匹配 → 拒绝执行、不写缓存；manifest 非法 → 同样拒绝。
3. 声明 `run` 动作走 `call`（`action:"run"`）；未声明直接跑 `command`，stdin 传参、stdout 为结果。
4. 产物收集三形状落位正确；默认删除工作目录，`--keep` 保留且不常驻。
5. 执行失败（退出码非 0）清理工作目录、不写缓存、日志记退出码。
6. 同来源同哈希重复执行命中缓存，不重新拉取；`--no-cache` 强制重拉。
7. `gqy-clean --expired` 回收超过 7 天的 oneshot 缓存，未到期不动。

# 024 · 并发与多租户

日期：2026-11-02
状态：完成

## 目标

让网关能同时扛住多个任务（每个任务可能开很多 agent/团队）：**租户级并发隔离 + 每分钟配额 + 低开销异步日志 + 统一对外规范**，并把非 GQY 的 agent 接入方式写成可照抄的文档。

## 范围

**做：**

- `routing.json` 的 `tenants`（`name` / `max_concurrency` / `req_per_min`）与校验（名字唯一、字符集、范围）。
- 租户池：独立并发信号量 + 每分钟固定窗口配额；排队超时 `tenant_queue_timeout`、超配额 `tenant_quota`（429 + Retry-After）、未登记 `tenant_unknown`（400）。
- 请求头 `X-GQY-Tenant` / `X-GQY-Task` 解析与校验（`invalid_tenant` 400）。
- 三层顺序：租户池 → 账号池 → 上游；租户槽在 Complete/Stream 全路径释放。
- 异步请求日志：有界队列 + 批量落盘 + 丢弃计数，日志不阻塞请求；`requests.jsonl` 增 `tenant` 字段。
- 观测：`/api/gateway/status` 增 `tenants`（in_flight/peak/queued/accepted/rejected/req_per_min/max_concurrency）。
- 文档：设计 [`16-并发与多租户.md`](../designs/16-并发与多租户.md)（MT1–MT8）+ 接入指南 [`reference/agent-onboarding.md`](../reference/agent-onboarding.md)。

**不做：**

- 跨租户借调 / 加权公平队列（保持 FIFO + 独立配额）。
- 租户级独立鉴权（当前租户名不是凭据，已列为风险）。
- 租户级模型白名单。

## 关键决定

- **租户槽先于账号槽**：先做便宜的拒绝（配额/未登记），再排队等上游容量。
- **日志异步化**：并发越高，同步 open/append/close 越贵；有界队列把 IO 从请求路径挪走，满了宁可丢弃也不阻塞。
- **状态常数开销**：每个租户一个信号量 + 一个计数器，短临界区。
- **未登记即拒绝**：配置了 `tenants` 后，名字不在表里直接 400，避免「随便写个名字绕过配额」。

## 验收

```bash
make check
cd app && go test -race ./...
```

行为验收：

1. 租户 A 打满并发时，租户 B 的请求仍立即成功（不受 A 拖慢）。
2. A 的后续请求按 `queue_timeout_ms` 超时，返回 `tenant_queue_timeout`，不无限等待。
3. `req_per_min` 超限返回 429 `tenant_quota` 且带 `Retry-After`。
4. 配置了租户后，未登记名字 400 `tenant_unknown`；空名字落 `default` 可用。
5. `/api/gateway/status` 返回每租户 in_flight/peak/accepted 等观测。
6. 请求完成后日志异步落盘、`requests.jsonl` 含 `tenant`；`Close()` 冲刷不丢。
7. 非法租户头 400 `invalid_tenant`；`X-GQY-Task` 别名可用。

## 留底

完成（2026-11-02）。`gofmt`/`vet`/`go test ./...`（14 包 0 失败）/`make check` 全绿。

测试：`TestTenantConcurrencyIsolation`（A 占槽，B 仍秒回，A 第二条走 tenant_queue_timeout）、`TestTenantQuotaPerMinute`（429 + Retry-After）、`TestTenantUnknownRejected`（400，空名落 default）、`TestTenantStatuses`（accepted/peak/max_conc）、`TestTenantHeaderValidation`（合法/非法/别名）；既有日志测试改为 `Close()` 后读取（异步写）。

性能基线（本机 Apple M2，`go test -bench BenchmarkCompleteParallel`，64 并发租户池、假适配器、含租户槽+账号槽+异步日志入队）：**2592 ns/op、2837 B/op、19 allocs/op**（网关自身开销，不含网络）。

偏差：

- 租户名来自请求头，**不是鉴权凭据**；真正的边界是「谁能连上网关」。要更强隔离需给每 agent 独立 token 并映射租户（后置，已记风险）。
- 日志队列满会丢弃并计数，未接监控告警。
- 公平性只有「租户内 FIFO」，不做跨租户借调。

# 020 · 安全硬化

日期：2026-11-02
状态：完成

## 目标

把安全边界从「文档写了」变成「代码守着、测试验着」：所有受保护端点对「未设令牌 + 非本机」一律 403；补上文档承诺但代码缺失的**工具日志**（S5），且写入前脱敏；用测试证明请求日志/工具日志不含密钥。

## 范围

**做：**

- 鉴权表驱动测试：11 条受保护路径（`/v1/*`、`/v1beta/*`、`/api/*`）在「无令牌 + 非回环」下全部 403 且错误体 `auth_required`。
- 实现工具日志：`<session>/logs/tools/YYYY-MM-DD.jsonl`，一行一次调用，字段 `timestamp/tool_name/status/duration_ms/input_summary/output_summary/artifact_paths`；目录 0700、文件 0600。
- 脱敏：`session.RedactText`（`sk-*`、`Bearer`、`api_key=`、`token=`、`password=`），工具日志的输入/输出摘要写前脱敏 + 截断 512 字节。
- agent loop 的 `tool` 事件写出时同步落工具日志（best-effort，不阻断对话）。
- 测试：脱敏规则、工具日志落盘且不含明文密钥、请求日志不含 api_key。

**不做：**

- 通用脱敏中间件（请求体/响应体全量脱敏）——后置。
- 密钥轮换、审计导出。

## 关键决定

- **脱敏在写入侧做**：工具日志与摘要统一走 `RedactText`，不依赖读侧过滤。
- **日志只记摘要不记正文**：输入/输出截断 512 字节；正文仍只存在会话事件流里（用户自己的数据）。
- **工具日志失败不阻断**：写日志失败只丢日志，不影响工具结果与 SSE。
- **鉴权按前缀**：`/api`、`/v1`、`/v1beta` 全覆盖；静态资源只服务 UI 不涉密。

## 验收


行为验收：

1. 无令牌 + 非本机：11 条受保护路径全部 403，错误体 `auth_required`。
2. 工具调用后 `logs/tools/<date>.jsonl` 出现一行，字段完整、`artifact_paths` 为数组。
3. 输入/输出含 `sk-…` / `Bearer …` / `api_key=…` 时，日志中为掩码，不含明文。
4. 网关请求日志（`gateway/requests.jsonl`）不含账号 api_key。

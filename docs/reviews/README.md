# 调研走查与试错案例

`reviews/` 按日期归档两类材料：

1. **外部调研**：精读外部项目/文档，提炼可借鉴的机制（只借思路，不复制实现）。
2. **试错案例**：团队协作、工程实践中出过的真实问题，记录「现象 → 根因 → 修法 → 教训」。

两类材料不只是给当前团队看的，也是给未来「全能代理」的案例库：她接手时可以先读这里，知道哪些环节会以什么方式出问题、当时怎么修的。

## 怎么新增一条

- 外部调研：写清「对象、日期、可借鉴的机制、GQY 采用/不采用、来源 URL」。
- 试错案例：写清「现象、根因、修法、教训、防再犯的规则/测试」。
- 新增后在本文件表格里加一行。

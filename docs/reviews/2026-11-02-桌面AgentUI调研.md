# 桌面 Agent UI 调研与生产化清单

日期：2026-11-02
范围：Cursor 3 / Devin Desktop / Claude Code Dynamic、Google Antigravity、Warp、LM Studio / Jan / Msty、AI SDK Tool Approval、16 AI Agent UI Patterns 等公开资料。

## 被反复验证的交互

1. **键盘优先**：⌘K 命令面板、快速切换会话、快捷键覆盖高频操作。Cursor、Linear、Raycast 系产品都把「不离开键盘」当默认工作方式。
2. **人在环上**：计划（Plan）、工具审批（Tool Approval）、产物评审（Artifact Review）是三个独立界面，不是把所有东西塞进聊天气泡。
3. **可回看的执行轨迹**：工具调用以时间线/卡片呈现参数、输出、耗时与状态；失败可重试，已完成的产物可单独打开。
4. **上下文与产物分栏**：聊天是输入面，右侧是上下文用量、产物、计划与 diff 的评审面。Antigravity 明确把 Artifact 作为跨表面交付物。
5. **本地应用形态**：LM Studio / Jan / Msty 都把模型、会话、设置放在本地；WebUI 只是同一进程的一个表面，桌面壳负责窗口、托盘、更新。
6. **渐进式披露**：默认只给结论与关键动作；思考、原始参数、长输出折叠，需要时展开。
7. **错误与恢复**：流中断、工具失败、审批拒绝都要有明确状态与下一步，不把错误混进正文。

## GQY 已对齐

- ⌘K 命令面板：会话搜索、控制台分类、新对话、主题与引导。
- 会话搜索、日期分组、侧边栏收起、URL `?session=` 回打开。
- 思考折叠、工具轨迹卡片、问题卡片、停止/重试。
- 右侧会话信息抽屉：上下文估算、工具、产物索引。
- 模型选择器：搜索、能力/供应商筛选、最近使用、路由组。
- 控制台：用量、模型、供应商、网关、插件、工具、外观、关于。
- PWA manifest + 图标 + 独立窗口；`make demo` 一键本地体验。
- 键盘快捷键、确认对话框、回到底部、六套主题。

## 还缺的生产能力

| 工具审批 | agent 直接执行核心工具 | 增加 `approval` 事件：shell / edit 执行前暂停，UI 卡片批准/拒绝/改参数 |

| 语音 | 无 | 先做文件上传转写，再考虑唤醒词 |
| 自动更新 / 签名 | 无 | GoReleaser + 平台签名；桌面壳更新通道 |

## 设计原则

- 聊天是输入面，评审是输出面：不要把计划、diff、产物都塞进消息流。
- 每个动作有可见状态：排队、执行中、成功、失败、取消、等待审批。
- 默认只显示结果与关键参数；原始输出与思考折叠。
- 键盘可达：⌘K、Enter、Esc、Tab 顺序、焦点可见。
- 本地优先：所有状态与文件在本机；界面只通过 HTTP API 读安全视图。

# 20 · 可观测与指标

依据：`00-设计理念.md` G7（可观测）、`02-网关与路由.md` R7、`08-鉴权与配额.md` A9；施工单 `028`。

## 范围

**做：**

- 一个 Prometheus text exposition 0.0.4 端点 `/metrics`，无第三方依赖。
- HTTP、网关、账号、插件、构建与配置版本五组指标。
- 路径模板归一，避免 session / plugin / model 名造成高基数。

**不做：**

- OpenTelemetry、tracing、远端 push gateway。
- 指标持久化、跨进程聚合。
- 指标进入 WebUI 看板（控制台先用 `/api/gateway/status`）。

## 决定

**M1 · 端点鉴权**：`/metrics` 与 `/api` 一样走 A1：设置 `GQY_AUTH_TOKEN` 时必须 Bearer/cookie；未设置时只允许本机。它不计入口限流，避免 Prometheus 周期性抓取被 429。

**M2 · 命名与标签**：

| 指标 | 类型 | 标签 |
| --- | --- | --- |
| `gqy_http_requests_total` | counter | `method`、`path`、`status` |
| `gqy_http_request_duration_seconds` | histogram | `method`、`path` |
| `gqy_gateway_calls_total` | counter | `provider`、`model`、`account`、`status` |
| `gqy_gateway_attempts_total` | counter | `provider`、`account` |
| `gqy_gateway_failures_total` | counter | `provider`、`account` |
| `gqy_gateway_tokens_total` | counter | `provider`、`account`、`direction` |
| `gqy_gateway_cooldown_seconds` | gauge | `provider`、`account` |
| `gqy_gateway_inflight` | gauge | `provider`、`account` |
| `gqy_plugin_calls_total` | counter | `plugin`、`action`、`status` |
| `gqy_plugin_failures_total` | counter | `plugin`、`action` |
| `gqy_plugin_ready` | gauge | `plugin` |
| `gqy_build_info` | gauge | `version`、`commit` |
| `gqy_config_version` | gauge | — |

**M3 · 内存态**：指标只存进程内存，重启清零；不写盘，不记录正文、密钥与 prompt。

**M4 · 路径归一**：`/api/sessions/<id>/…` → `/api/sessions/{id}/…`；`/api/plugins/<id>/…` → `/api/plugins/{id}/…`；`/api/memory/<persona>/…` → `/api/memory/{persona}/…`；`/v1beta/models/…` → `/v1beta/models/{model}`；其余固定路径原样。

**M5 · 直方图桶**：`0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10, +Inf` 秒，够单机网关用；不按状态码拆分直方图。

**M6 · 失败标签**：网关终态 `status` 取 `ok` / `error` / `no_candidate`；插件调用 `status` 取 `ok` / `error` / `timeout` / `canceled`。解析阶段失败没有 provider 时，`gqy_gateway_calls_total` 不产生样本，避免空标签序列。

## 验收

1. `curl /metrics` 文本可被 Prometheus 解析；无密钥/正文。
2. 设置令牌后无 bearer 401；本机 + 未设置令牌放行。
3. 一次成功对话后 `gqy_gateway_calls_total{status="ok"}`、attempts、tokens 增加。
4. 429/冷却后 cooldown gauge 反映剩余秒数；全部冷却返回 `no_candidate`。
5. `/metrics` 不因入口限流返回 429。

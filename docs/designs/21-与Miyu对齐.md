# 21 · 与 Miyu 对齐

依据：`00-设计理念.md` 的 G1（本地优先）、G4（插件可扩展）；`10-前端界面.md` 的 FE1–FE9；`01-架构.md` 的 D2（零构建 JS）。用户 2026-11-02 定：项目与 [`miyu-agent/miyu`](https://github.com/miyu-agent/miyu) 功能完全对齐，持续到做出可用的 macOS app，UI 与功能一模一样。

## 范围

**做：**

- 以 Miyu 的产品形态为对齐目标：核心能力、网页（`miyu-agent/miyu-web`）、macOS 桌面端（`miyu-agent/miyu-desktop`）的页面、交互、行为逐项对齐。
- 交付一个可用的 macOS app：双击即用，不依赖终端；对话、管理页、插件、记忆、知识库、语音等能力可用。
- 逐页、逐行为建立对照清单，完成一项勾掉一项；对照清单进 `docs/construction/`，随施工单更新。
- 先写文档再改代码：每进入一个阶段，先补本文件与对应蓝图，再开工。

**不做（在本设计里）：**

- 不复制 Miyu 的代码、页面文件、样式表、图标与角色素材。Miyu 的代码是 AGPL-3.0-or-later，GQY 是 PolyForm Noncommercial 1.0.0；两套许可不能混着发（PA2）。
- 不照搬 Miyu 的内核协议与事件溯源架构。GQY 保留 Go 网关 + `/api` + SSE 的形态；对齐的是用户看见、用到的功能（PA1）。
- 不在这一版重开零构建形态（10 FE1）与本地优先（00 G1）。
- 不做终端界面（TUI）与 QQ 等通讯平台客户端；它们是 Miyu 的另外两个头，macOS app 不包含（PA6）。

## 决定

### PA1 · 对齐目标与边界

- 对齐的是产品能力与用户可见行为，不是内部协议与代码结构。
- GQY 保留 Go 网关、`/api` + SSE、零构建 JS、WKWebView 外壳；不引入 Rust 内核、不重写为事件溯源。
- Miyu 文档里未定的交互不抢先实现；先记录在对照清单的「待定」列，等 Miyu 定了再跟。

### PA2 · 许可边界：独立实现，不复制

- Miyu 三个仓库都是 AGPL-3.0-or-later；GQY 是 PolyForm Noncommercial 1.0.0。两套许可不能混着发。
- 不复制 Miyu 的源码、页面文件、样式表、图标、角色素材、字体子集。公开文档、截图、可见行为作为规格；代码、HTML、CSS 由 GQY 自己写。
- 需要第三方素材（图标、字体、Markdown/公式渲染库）的，按素材自己的许可证引入，登记在 `docs/third-party/`，保留原文与署名。
- 如果将来确认 Miyu 与 GQY 同属一个版权人并决定合并许可，另开设计决定；在那之前按本条执行。

### PA3 · UI 规格的来源与版本

- 网页以 `miyu-web` 的 `docs/blueprint/web.md`、`web-ui.md` 为规格，外壳以 `miyu-desktop` 的 `docs/blueprint/desktop.md` 为规格。
- 规格引用记提交号；Miyu 改了规格，GQY 在对照清单里记差异，不自动跟。
- 视觉参数（颜色、字号、行高、间距、圆角、动效时长）按规格实现；实现走 GQY 自己的 CSS 令牌体系（`app/styles/tokens.css`），不引入 Miyu 的样式文件。

### PA4 · 验收口径：真实路径、逐页对照

- 每阶段验收必须走生产代码路径：真实 Go 服务、真实 WKWebView、真实上游；不建 mock 冒烟资产（沿用 00 与既有规矩）。
- 对照清单逐项写「Miyu 的行为 / GQY 的行为 / 结论」；没做到的不勾。
- macOS app 的验收以「双击可开、关窗不退出、托盘可回、退出停服务、外链走浏览器、下载进下载目录」为最小集。

### PA5 · 外壳行为对齐

- 单实例：第二次启动把已有窗口拿到最前并退出。
- 窗口状态：记住大小、位置、最大化；首次 75% 屏、不小于 1100×760、不超过 90%、居中。
- 关窗口只藏起；点 Dock 图标或托盘「显示 GQY」拿回来。
- 退出（托盘、⌘Q）：先停 Go 服务再退；系统关机/注销只退外壳，不主动停服务。
- 外链与新窗口交系统浏览器；下载进「下载」目录、重名加编号。

### PA6 · TUI 与通讯平台后置

- macOS app 不包含终端界面（TUI）与 QQ/OneBot 客户端；它们是 Miyu 的另外两个头。
- 「功能完全对齐」在本设计里指 app 内可见、可用的能力；TUI、IM 另立设计。

### PA7 · 主线与支线

- 本对齐是当前主线；用户其他指令作为支线，不打断主线（沿用 14 GL1–GL6）。
- 每个施工单只做一阶段里的一块，不把多个阶段混进一个提交。

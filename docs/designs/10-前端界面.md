# 10 · 前端界面

依据：`00-设计理念.md` 的 G1（本地优先）、G6（安全与配额兜底）；`01-架构.md` 的 D2（零构建 JS）、前端层职责；`02-网关与路由.md` 的 R8（端点与鉴权）；`03-协议翻译.md` 的 C2（响应事件流）；`05-会话与产物.md` 的 S2/S3/S4；`06-工具.md` 的 T9（工具轨迹）；`08-鉴权与配额.md` 的 A8（密钥只写不读）；`09-存储.md` 的 ST2（真相与派生）、ST6（脱敏）。

## 范围

**做：**

- 零构建形态：`index.html` + 原生 JS 模块 + CSS，由 Go 静态托管。
- 页面清单与每页职责：对话（输入框 / 消息流）、灯箱、设置、看板、用量、初始化引导、关键词浮窗。
- 消息结构：五种 SSE 事件（thinking / tool / text / question / done）渲染成消息块。
- 思考折叠、工具轨迹、ask_user 卡片、产物灯箱的渲染。
- 草稿、重试 / 停止、附件上传（拖拽 / 选择）的交互。
- 状态与本地存储边界；密钥只存服务端，前端只见 `api_key_set`。

**不做（后置）：**

- 引入构建链或前端框架：01 D2 已定零构建，不在此重开。
- TypeScript 化：开放项只指一句（条件见 01 D2），本文不展开。
- 语音唤醒词、浏览器自动化等新交互形态。
- 多用户、会话分享、云端同步（05 已后置）。
- 会话全文检索、向量知识库的界面（关键词匹配先行）。

## 决定

### FE1 · 零构建形态：index.html + 原生 JS 模块 + CSS

- 前端由 Go 进程静态托管：`index.html` + 原生 JS 模块 + CSS，无构建链，改完即刷新（01 D2）。
- JS 模块按职责拆分：api / store / render / chat / settings / board / glossary / markdown / i18n / menu 等；CSS 用令牌，暗色主题走 `data-theme=dark`。
- 前端不直接碰文件系统，不保存密钥（01 分层表）；TypeScript 化开放项只指一句：条件见 01 D2。

### FE2 · 视图与浮层

- 两个视图：对话（主视图）、看板；其余为浮层：设置、用量、扩展、灯箱、初始化引导。
- 侧栏入口：对话、看板、扩展、设置。
- 关闭顺序：Esc 先关浮层，再看板，最后回对话；窄屏看板三列改纵向堆叠。

### FE3 · 页面清单与职责

| 页面 | 职责 | 数据来源 |
| --- | --- | --- |
| 对话 | 输入框 + 消息流；发送、停止、重试、附件、消息块渲染 | `/api/chat`（SSE）、`/api/sessions` |
| 灯箱 | 产物查看：文件面板、代码高亮、图片预览 | `/api` 产物接口 |
| 设置 | 模型 & 供应商、路由组、工具开关、人设、记忆、知识库、用量、软件包、扩展、账户、语音 | `/api/models`、`/api/tools`、`/api/plugins`、`/api/usage`、`/api/gateway/status` 等 |
| 看板 | 本机任务卡：todo / doing / done，可增删改、移动、关联会话 | localStorage |
| 用量 | 本地占用、token、7 天趋势、各 provider 调用；顶栏 ⚡ 浮层保留 | `/api/usage`、`/api/gateway/status` |
| 初始化引导 | 首次打开三步：工作区名称 → 模型（可空）→ 动效偏好；可跳过，设置里可重开 | `/api/models` + localStorage |
| 关键词浮窗 | 正文术语点按浮层：术语、定义、来源；设置「知识库」tab 维护术语表 | localStorage 术语表 |

- 设置页的「模型 & 供应商」与「路由组」沿用 02 的 providers.json / routing.json 语义，只做展示与编辑入口，不重定规则。
- 用量是设置页的子 tab，不单独占一个视图。

### FE4 · 消息结构：五种 SSE 事件渲染成消息块

前端只认 05 S2 的五种事件，按序把事件流重建为消息块：

| 事件 | 渲染 |
| --- | --- |
| `thinking` | 思考块，默认折叠 |
| `tool` | 工具轨迹块：参数 / 输出 / 耗时 / 状态 |
| `text` | 正文块，增量追加 |
| `question` | ask_user 卡片 |
| `done` | 结束标记：用量与停止原因 |

- 事件是追加的投影（05 S2）：非流式请求返回同样的事件序列，只是不逐块推送。
- agent 层已把 provider 层的 `tool_call` / `usage` 投影成 S2 事件（03 C2）；前端不感知 provider 层事件。

### FE5 · 思考、工具轨迹、ask_user 卡片、灯箱

- 思考块默认折叠，可展开；回复结束后可按用户偏好保持展开。
- 工具轨迹块一次调用一块（06 T9）：参数、输出、耗时、状态；`status` 为 error / timeout / canceled 时标色，长输出截断可展开。
- ask_user 卡片：选项带数字键 1..n，也可输入自定义答案；用户作答前正文暂停，作答后回填继续（06 T7）。
- 产物灯箱：消息关联的产物进入灯箱，支持文件面板、代码高亮、图片预览（05 S3）；`write_artifact` 的多文件产物按真实路径建树展示。

### FE6 · 草稿、重试、停止

- 草稿按会话保存，存服务端会话数据；切换会话保存并恢复输入框内容（05 S4）。
- 停止：前端发停止信号，服务端取消在途请求（AbortController 语义）；已产出增量保留，进行中的工具标 `canceled`（06 T1）。
- 重试：以当前消息为界重新发起一轮，不覆盖历史；旧回复标记为被替代并折叠（05 S4）。

### FE7 · 附件上传交互

- 支持拖拽与点击选择两种入口；文本文件注入上下文、图片走多模态、其他二进制落盘（05 S3）。
- 前端做类型与大小预校验；同名并发不覆盖由服务端 O_EXCL 保证（05 S3）。
- 上传中显示进度，失败显示原因；图片上传后可在输入区预览、移除。

### FE8 · 状态与本地存储

- 服务端会话数据为真相：会话列表、消息、草稿、产物，走 `/api` 读写（05 S5、09 ST2）。
- localStorage 只放 UI 偏好与轻量状态：主题、语言、reduceMotion、上次视图、看板卡、术语表、语音开关；不存消息正文与密钥。
- 密钥只存服务端：设置页保存后只看到 `api_key_set`，不回显明文（08 A8、09 ST6、12 CF8）。
- 离线：会话数据在本机数据根，断网仍可读历史（G1）。

### FE9 · 鉴权与安全边界

- 所有 `/api`、`/v1` 请求带 cookie / Bearer（02 R8），前端不自行存访问令牌之外的密钥。
- 前端不保存密钥、不落 prompt / 回复正文（G6）；文件访问走服务端接口，不直连文件系统。
- 设置页「模型 & 供应商」只展示 `api_key_set`；密钥写入走专用写接口，不读回。

## 验收

1. 零构建：修改 JS / CSS 后刷新即生效，无构建步骤。
2. 五种事件按序渲染成消息块；非流式与流式渲染结果一致（对照 05 S2）。
3. 思考块可折叠 / 展开；工具轨迹显示参数、输出、耗时、状态；ask_user 卡片数字键与自定义答案都能回填。
4. 草稿切会话不丢；停止后已产出增量保留；重试后旧回复折叠为被替代。
5. 拖拽 / 选择上传：文本注入、图片多模态、二进制落盘均可用；同名并发不覆盖。
6. 设置页不出现明文密钥，只显示 `api_key_set`。
7. localStorage 只含 UI 偏好，无密钥与消息正文。

# 06 · 工具

依据：`00-设计理念.md` 的 G4（插件可扩展）、G5（评测驱动）、G6（安全与配额兜底）；`01-架构.md` 的 tool 层职责；`02-网关与路由.md` 的 R8（端点与鉴权）；`04-插件运行时.md` 的 P11（工具注册）；`05-会话与产物.md` 的 S2（事件模型）、S5（目录与工具日志）。

## 范围

**做：**

- 工具契约：一次调用的六个要素与统一结果形状。
- 核心工具（内置、自动注入）：read / edit / shell / list_dir / websearch / ask_user，各自职责与边界。
- ask_user：选项 / 数字键 / 自定义答案，对接 05 的 S2 `question` 事件。
- 外部工具：provider_usage + 插件动作（引用 04 的 P11），运行时开关 `GQY_ENABLE_EXTERNAL` 与 `/api/tools/external`。
- 工具轨迹在消息里的呈现（引用 05 的 S2 `tool` 事件）。
- 沙盒边界只给指针，细节留给 `11-安全与沙盒.md`。

**不做（后置）：**

- 完整沙盒实现与权限系统（`11-安全与沙盒.md`）。
- 新核心工具的随意扩张：加一个核心工具先过评测与安全两条线。
- 工具结果多模态：图片以外的二进制结果不进模型上下文。
- 流式工具输出、工具级配额与限流。
- 浏览器自动化、技能市场等新工具形态。

## 决定

### T1 · 工具契约：一次调用六要素，结果统一为文本 + 状态

工具最小契约只有五个能力：名称、描述、参数 JSON Schema、执行、来源标记。执行语义统一为：

执行(上下文, 参数) → (结果文本, 错误)

- 参数是 JSON 对象；JSON Schema 声明参数形状，直接给模型看。
- 结果统一为文本：成功时是回填给模型的字符串；失败时返回错误文本。
- 来源标记只有两种：核心（自动注入）与外部（开关控制，见 T2）。

一次工具调用的完整记录固定六个字段：

```json
{
  "name": "read",
  "schema": {"type": "object", "properties": {"path": {"type": "string"}}, "required": ["path"]},
  "arguments": {"path": "README.md"},
  "result": "…文件内容…",
  "duration_ms": 12,
  "status": "ok"
}
```

- `status` 只取 `ok` / `error` / `timeout` / `canceled`。
- 出错时 `result` 为空，改由 `error` 字段携带错误文本。
- 六个字段落进工具轨迹（T9）与工具日志（05 S5）；模型只看到 `result` 或 `error`。

### T2 · 来源与注入：核心自动注入，外部默认关

- 核心工具是 agent 内置能力，注册后始终自动注入模型工具列表。
- 外部工具（provider_usage、插件动作）默认不注入；`GQY_ENABLE_EXTERNAL=1` 或运行时开关开启才可见（见 T8）。
- 判断准则：外部工具失败不能拖垮核心链路；关掉开关后模型根本看不到外部工具。

### T3 · 注册表：重名报错，注销幂等

- 工具名全局唯一；重名注册返回错误，不静默覆盖。
- 注销不存在返回「未找到」，不报错、不 panic。
- 核心与外部两份列表分开：核心列表用于默认注入，外部列表由开关过滤。
- 插件动作注册成外部工具的命名规则见 04 的 P11：`<pluginID>__<action>`，非字母数字转 `_`，最长 64。

### T4 · 核心工具：职责与边界一张表

| 工具 | 职责 | 边界 |
| --- | --- | --- |
| `read` | 读文件内容；图片转 base64 供视觉理解 | 只读允许根内路径；文本上限 10 MB，超过报错不整读 |
| `edit` | 覆盖写文件，自动建父目录 | 只写允许根内路径；同目录临时文件 + rename 原子写；保留已有权限 |
| `shell` | 执行一条 shell 命令 | 工作目录固定 workspace；默认超时 60s；输出上限 16 KB；超时杀进程组；白名单可选 |
| `list_dir` | 列出目录项，每行一项 | 只读允许根内目录；目录项以 `/` 结尾；路径缺省为当前目录 |
| `websearch` | 网络搜索 | 后端未配置时明确返回错误，不编造结果 |
| `ask_user` | 向用户提问，拿回答案后继续 | 见 T7；是唯一会暂停 loop 的核心工具 |

- 六者全部标记为核心，自动注入。
- `write_artifact` 也是核心工具，但归产物域：一次写多个交付文件，对齐 05 的 S3；单文件 ≤ 2 MB，一次最多 20 个文件，总量 ≤ 2 MB，先整体校验再写，不留半截产物。

### T5 · read 与 edit：文件工具边界

- read：只访问允许根内路径；先查文件大小，超过 10 MB 直接报错，不整读进内存；图片（png / jpg / jpeg / gif / webp）转 data URI 供视觉模型，其余按 UTF-8 文本返回。
- edit：参数是完整文件内容，覆盖语义，不是 diff；同目录临时文件 + rename 原子写；已有文件保留原权限，新文件 0644；自动建父目录。
- 两者都经路径沙箱解析：相对 workspace 或绝对路径均可，防 `../` 与符号链接逃逸；沙箱实现细节在 `11-安全与沙盒.md`，这里只定工具边界。

### T6 · shell：固定工作目录，超时与输出双上限

- 工作目录固定为 workspace，不接受参数改目录。
- 单条命令默认超时 60s；合并输出（stdout + stderr）默认保留 16 KB，超出截断并标记。
- 超时或取消时杀整个进程组（连同子进程），不残留孤儿。
- 白名单可选：`GQY_SHELL_ALLOWLIST` 非空时只允许列表内命令（按首 token 的 basename），并拒绝 `; | & > <` 等可串联、重定向的元字符，防止绕过；未设置时执行任意命令，并把当前策略如实写进工具描述。

### T7 · ask_user：选项 / 数字键 / 自定义答案

- 参数：`question`（必填）+ `options`（2–4 个字符串，可选）。
- 语义：模型需要用户拍板时调用；不要问自己能推断的事。
- 执行即「暂停」：不返回普通结果，而是给出需要用户输入的信号，agent loop 捕获后暂停。
- 前端按 05 的 S2 `question` 事件渲染：选项带数字键 1..n，也可以输入自定义答案。
- 用户回答后回填给 loop，模型接着跑；答案作为下一轮上下文，不重新走工具调用。

```json
{"question": "要用哪个模型？", "options": ["deepseek", "moonshot", "其他"]}
```

### T8 · 外部工具与运行时开关

- 外部工具两个来源：`provider_usage`（查询供应商余额 / 用量）+ 插件动作（04 的 P11）。
- `provider_usage`：无参数；返回可用性、货币、余额；余额低于阈值时带「尽快收尾」提示；未配置密钥或供应商未实现时返回明确错误。
- 开关：`GQY_ENABLE_EXTERNAL=1` 开启注入；运行时接口 `/api/tools/external` 读写当前开关，受 02 的 R8 鉴权覆盖；设置页同源。
- 关闭开关 = 模型工具列表不出现任何外部工具；已注册的外部工具仍可通过 HTTP 单独调试调用。

### T9 · 工具轨迹：消息里一次调用一个 tool 事件

- 一次工具调用在回复里对应 05 S2 的一个 `tool` 事件：开始 / 参数 / 输出 / 耗时 / 状态。
- 消息历史里工具调用存成 `tool` 消息（工具名 + 参数 + 结果），供重试与回放。
- 落盘按 05 S5：`logs/tools/<日期>.jsonl` 一行一条，字段至少 timestamp、tool_name、status、duration_ms、input_summary、output_summary、artifact_paths；敏感参数脱敏（G6）。

### T10 · 沙盒边界：这里只给指针

- 文件类工具（read / edit / list_dir）的路径解析、shell 的工作目录与白名单，属于工具执行策略。
- 允许根、拒绝路径、符号链接逃逸防护、shell 元字符策略的完整实现与威胁模型，交给 `11-安全与沙盒.md`。
- 工具层只消费沙盒策略，不自己发明安全规则。

## 数据样例

一次 `tool` 事件（05 S2）：

```json
{"type": "tool", "name": "edit", "arguments": {"path": "a.txt", "content": "hi"}, "result": "已写入 a.txt（2 字节，权限 0644）", "duration_ms": 8, "status": "ok"}
```

`ask_user` 参数：

```json
{"question": "要继续吗？", "options": ["继续", "取消"]}
```

## 验收

1. 契约：每个工具返回文本或错误，六字段记录齐全；重名注册报错、重复注销幂等。
2. read：大文件超限报错；图片返回 data URI；越界路径被拒。
3. edit：原子写不产生半截文件；保留原权限；父目录自动创建。
4. shell：超时杀整组；输出截断标记；白名单拒绝 `;` 等元字符。
5. ask_user：暂停 loop，`question` 事件带选项；数字键与自定义答案都能回填。
6. 外部工具：开关关闭时模型工具列表无外部工具；开启后 provider_usage 与插件动作出现（04 P11）。
7. 轨迹：一次调用对应一个 `tool` 事件与一条 jsonl 日志；敏感参数脱敏。

# 09 · 存储

依据：`00-设计理念.md` 的 G1（本地优先）、G6（安全与配额兜底）、G7（可观测）；`01-架构.md` 的 D4（`gqy-clean` 管清理）；`02-网关与路由.md` 的 R7（请求日志）；`05-会话与产物.md` 的 S5/S6（会话目录与 TTL）；`12-配置与热更新.md` 的 CF（配置清单）。

## 范围

**做：**

- 数据根 `$GQY_HOME` 的完整布局与目录权限。
- 文件格式约定：JSON 配置、JSONL 追加日志、manifest。
- 原子写与崩溃安全：写不写坏、坏行不拖垮启动。
- 请求日志、工具日志的轮转与清理。
- 清理入口 `gqy-clean`。

**不做（后置）：**

- 不引入数据库或嵌入式 KV：单机单用户，文件系统足够，换来零依赖与可手工排查。
- 不做会话全文检索索引（后置到知识库/记忆主题）。
- 不做云同步、多机一致、备份策略。

## 决定

### ST1 · 数据根唯一

- 所有持久化都在 `$GQY_HOME` 下，默认 `~/.gqy`；会话级数据在 `$GQY_HOME/sessions/$SESSION_ID/`（目录规范见 05 S5）。
- 配置、日志、插件目录互不嵌套：配置是配置，日志是日志，插件是插件，职责不混。

### ST2 · 真相与派生

- **真相** = 追加写的事件/日志（请求日志、工具日志、消息事件流）。真相只追加，不原地改。
- **派生** = 能由真相重建的东西（会话列表索引、统计、上下文快照）。派生数据丢了可以重建，不值得为它做强一致。
- 判断一个文件该放哪：先问「删了它，真相还在吗」。还在 → 派生，可随时重建。

### ST3 · 文件格式

| 类型 | 格式 | 规则 |
| --- | --- | --- |
| 配置 | JSON | 读入时整体校验，校验失败用旧快照（12 CF4） |
| 请求日志 | JSONL | 一行一个请求，字段见 02 R7，不落正文 |
| 工具日志 | JSONL | 一行一次调用，字段见 05 S5，敏感参数脱敏 |
| 会话清单 | JSON | `manifest.json`，字段见 05 S5 |

### ST4 · 原子写

- 写文件一律「临时文件 + 写完 + rename」：任何时刻读到的是完整旧版或完整新版，不会是半截。
- 追加日志按行写、写完整行；读取方遇到损坏行跳过并计数，不因一行坏而放弃整个文件。
- 配置切换是内存里的快照替换（12 CF5），落盘用同一个原子写。

### ST5 · 崩溃安全

- 追加日志幂等：启动时从最后一个完整事件之后继续，重复行按事件 id 去重。
- 会话可从消息事件流重建到最后一个完整回合；重建不了的部分标记为不完整，不假装成功。
- 配置与 manifest 走原子写，崩溃最多丢最后这次未 rename 的改动，不回退到更早。

### ST6 · 权限与脱敏

- 目录 0700、敏感文件 0600；数据根创建时强制。
- 密钥不落盘（内存态），配置里的 `api_key` 允许为空、回退环境变量；前端只见 `api_key_set`（12 CF8）。
- 日志与上下文明文脱敏：不记录密钥、token、完整环境变量、prompt/回复正文（G6、R7）。

### ST7 · 轮转与清理

- 请求日志、工具日志按日期或大小轮转，轮转后旧文件可被 TTL 清理。
- 会话临时目录默认保留 7 天，工具日志与上下文快照 30 天（05 S6）；均可配置。
- 清理入口只有 `gqy-clean`：`--session <id>` 清单个会话，`--expired` 按 TTL 清过期数据；清理前先核对路径在数据根内，防越界删除。

## 数据布局

```
$GQY_HOME/
  providers.json          # 配置：多 provider 多账号（02 R5）
  routing.json            # 配置：路由组（02 R2）
  settings.json           # 配置：设置（12 CF）
  gateway/
    requests.jsonl        # 请求日志（02 R7）
  sessions/
    <SESSION_ID>/         # 会话数据（05 S5）
      manifest.json
      tmp/ logs/ io/ scripts/
  plugins/
    <plugin-id>/          # 插件目录（04 P3）
      manifest.json
```

## 验收

1. 配置写坏（半截 JSON）时，服务仍用旧快照运行，日志记录校验失败。
2. 日志追加一行损坏，启动时跳过该行并计数，其余行可读。
3. `gqy-clean --expired` 只清过期数据，未到期会话不动；路径越界被拒绝。
4. 数据根目录权限 0700，敏感文件 0600；密钥与正文不出现在任何落盘文件里。

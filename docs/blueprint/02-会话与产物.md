# 02 · 会话与产物

对应设计：`../designs/05-会话与产物.md`（S1–S7）、`../designs/09-存储.md`（ST1–ST7）。
状态：草稿（2026-11-02，施工单 005 进行中）。

## 会话

- 会话 id：`^[a-z0-9][a-z0-9-]{0,63}$`；随机 16 字节 hex。
- 全部会话在 `$GQY_HOME/sessions/<id>/`；`Store.Create` 建目录与 `manifest.json`。
- `manifest.json` 字段：`session_id`、`workspace`、`created_at`、`artifacts`、`cleanup_policy`（tmp 7 天、日志 30 天）。
- 目录：`tmp/{uploads,generated,scratch}`、`logs/tools`、`io/{input,output,context,webui}`、`scripts`；目录 0700、文件 0600。
- 删除前 `storage.EnsureInside` 校验真实路径在 `sessions/` 内；`../` 与符号链接逃逸被拒绝。

## 事件流

真相源：`io/context/messages.jsonl`，一行一个事件，只追加。

| 类型 | 字段 | 说明 |
| --- | --- | --- |
| `user` | `content` | 内部日志类型，不是对外五事件 |
| `thinking` | `delta` | 思考增量 |
| `text` | `delta` | 正文增量 |
| `tool` | `tool_name`、`phase`、`arguments`、`output`、`duration_ms`、`status`、`artifact_paths` | `phase` 为 `start` / `result`；`edit` 等写文件工具带产物路径 |
| `question` | `options`、`allow_custom` | 预留给 `ask_user` |
| `done` | `usage`、`stop_reason` | 收尾 |
| `branch` | `content`、`output` | 主线抢占时排队的支线消息与执行结果（013/014），不属于对外五事件 |

- `ReadEvents` 跳过损坏行并返回计数，不因一行坏而放弃整个文件。
- `Rebuild` 把事件投影成消息：`user` 起一条用户消息；其余累积进当前助手消息；`done` 标记 `complete`；没有 `done` 的尾部标记 `incomplete`。

## HTTP 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 创建会话，body `{"workspace":"…"}` |
| GET | `/api/sessions` | 列表，按创建时间倒序 |
| GET | `/api/sessions/{id}` | manifest + 重建消息 |
| DELETE | `/api/sessions/{id}` | 删除会话目录 |
| GET/PUT | `/api/sessions/{id}/draft` | 草稿读取 / 保存 |
| POST | `/api/sessions/{id}/uploads` | multipart `file`；O_EXCL 防覆盖 |
| POST | `/api/sessions/{id}/artifacts` | 追加产物索引 |
| POST | `/api/chat` | 走同一网关，把 provider 事件投影成五事件 SSE 并落盘 |

`/api/chat` 请求：`{"session_id":"…","model":"…","messages":[{"role":"user","content":"…","images":["data:…"]}]}`；省略 `session_id` 时新建会话。返回 SSE：

```json
{"type":"thinking","delta":"…"}
{"type":"text","delta":"…"}
{"type":"tool","tool_name":"read","phase":"start","arguments":{…}}
{"type":"done","usage":{"prompt_tokens":1,"completion_tokens":2},"stop_reason":"end_turn"}
```

## 清理

`gqy-clean --session <id>` 删除单个会话；`gqy-clean --expired` 按 manifest 的 `cleanup_policy.logs_ttl_days` 删除过期会话。两者都先做路径校验。

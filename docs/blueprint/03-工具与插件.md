# 03 · 工具与插件（当前实现）

## 1. 状态

已实现（2026-11-02）。

## 2. 对应设计决定

T（工具）：

- T1 工具契约：名称 / 描述 / Schema / 执行 / 来源，一次调用六要素记录。
- T2 来源与注入：核心自动注入，外部默认关。
- T3 注册表：名称唯一，重名报错，注销幂等，核心 / 外部分开。
- T4 核心工具：read / edit / shell / list_dir / websearch / ask_user。
- T5 read / edit 边界：10 MiB 上限、图片 data URI、原子写、保留权限。
- T6 shell 边界：固定 workspace、60s 超时、16 KiB 输出、进程组回收、白名单。
- T7 ask_user：question + options（2–4），暂停 loop，数字键 / 自定义答案。
- T8 外部工具与开关：provider_usage + 插件动作，`GQY_ENABLE_EXTERNAL`。
- T9 工具轨迹：一次调用一个 tool 事件 + 一条 jsonl 日志。
- T10 沙盒指针：落地 SEC2–SEC4。

P（插件运行时）：

- P1 统一调用模型：调用(插件ID, 动作, 参数) → (内容, 错误)。
- P2 注册中心：显式指定 → 社区名匹配 → 探测，歧义报错。
- P3 manifest：字段与校验，`$GQY_HOME/plugins/<id>/manifest.json`。
- P4 适配器：原生 stdio JSON-RPC、MCP stdio、unix / tcp 远程。
- P5 生命周期：discovered → loading → ready → closing → closed，外加 failed。
- P6 并发模型：concurrent / single-channel / exclusive，请求序号多路复用。
- P7 调用超时与取消：deadline 取 timeout_ms，晚到结果丢弃。
- P8 进程回收：EOF 自退 → 5s → SIGTERM → 2s → SIGKILL，整组杀。
- P9 热更新：安装 / 卸载 / 重装幂等，重扫不重启。
- P10 依赖：provides / requires 前置检查。
- P11 工具注册：`pluginID__action`，外部工具默认不注入。
- P12 可观测：`/api/plugins` 状态与调试调用。

NX（一次性插件）：

- NX1 定位：执行模式不是新格式，manifest 加 `mode:"oneshot"`。
- NX2 来源四级：本地 / git / url / 内置注册表，拉取后校验哈希。
- NX3 执行形态：声明 `run` 动作走 JSON-RPC，否则直接跑 `command`。
- NX4 生命周期：拉取 → 校验 → 执行 → 收集 → 默认清理，`--keep` 保留。
- NX5 与常驻关系：不注册工具、不占实例表。
- NX6 缓存：键 = 来源 + 版本 / 哈希，TTL 7 天。
- NX7 安全：执行即信任，来源显式指定，哈希防篡改。

## 3. 具体形状（代码事实）

### 3.1 工具契约与注册表（app/internal/tool）

契约接口：`Name()`、`Description()`、`Schema()`、`Execute(ctx, args) (string, error)`、`Source()`。

- 来源枚举 `Source`：`SourceCore`（0）、`SourceExternal`（1）。
- 六要素记录 `Record`（T1）：

```json
{"name":"read","schema":{…},"arguments":{…},"result":"…","error":"","duration_ms":12,"status":"ok"}
```

- `status` 四常量：`StatusOK` / `StatusError` / `StatusTimeout` / `StatusCanceled`。
- 统一错误：`ErrNotFound`、`ErrInvalidArgument`、`ErrTimeout`。

注册表 `Registry`：

- 内部两个 map：`core` 与 `external`。
- `Register`：重名返回错误，不覆盖；按 `Source()` 分表。
- `Unregister`：不存在返回 `ErrNotFound`（带错误，幂等语义）。
- `Get` / `Core()` / `External()`；`Core()` / `External()` 按名称排序返回。

**实现与蓝图差异 ①**：`Unregister` 对不存在返回错误 `ErrNotFound`，blueprint/tool.md 写「不报错」；语义等价（调用方可忽略），措辞不一致。

### 3.2 核心工具（app/internal/tool/builtin.go、ask.go）

| 工具 | 实现类型 | 参数 | 上限 / 默认 | 行为 |
| --- | --- | --- | --- | --- |
| `read` | `ReadTool{Policy}` | `path` 必填 | `MaxReadBytes = 10 << 20` | 图片（.png/.jpg/.jpeg/.gif/.webp）转 data URI；目录报错；超限报错不整读 |
| `edit` | `EditTool{Policy}` | `path`、`content` 必填 | 新文件 0644；父目录 0750 | `RejectSymlink` 拒绝符号链接目标；`.gqy-edit-*` 临时文件 + rename 原子写；保留原权限 |
| `shell` | `ShellTool{Policy}` | `command` 必填 | 超时 60s；输出 16 KiB | `/bin/sh -c`，cwd=workspace；超时 `killGroup`（SIGKILL 进程组）；截断标记 `\n...[截断]`；白名单拒绝元字符 |
| `list_dir` | `ListDirTool{Policy}` | `path` 可选（默认 `.`） | — | 排序输出，目录项加 `/` |
| `websearch` | `WebSearchTool{Policy}` | `query` 必填 | `Policy.WebSearchBackend` | 后端空 →「后端未配置」；已配置 →「调用暂未实现」 |
| `ask_user` | `AskUserTool` | `question` 必填；`options` 可选 | options 2–4（0 个也允许） | 返回 `AskError{Question{question, options, allow_custom}}`，loop 捕获后暂停 |

**实现与蓝图差异 ②**：websearch 在配置后端后返回「调用暂未实现」stub（blueprint/tool.md 只要求「未配置时报错不编造」）。

### 3.3 沙盒规则（app/internal/tool/sandbox.go）

`Policy` 字段：`Workspace` / `Roots` / `Denied` / `ShellTimeout`（int，秒）/ `MaxOutput`（int，字节）/ `ShellAllowlist` / `WebSearchBackend`。

- `Resolve` 固定顺序：相对 workspace 绝对化 → `Clean` → `canonicalPath`（最近已存在祖先 EvalSymlinks）→ 先 `Denied` 后 `Roots`。
- `RejectSymlink`：写目标为符号链接时拒绝。
- 常量：`DefaultShellTimeout=60`、`DefaultMaxOutput=16*1024`、`MaxReadBytes=10<<20`。
- shell 白名单：`checkAllowlist` 按首 token basename；元字符 `; | & > < ` $ ( ) \n` 拒绝。

### 3.4 插件运行时（app/internal/plugin）

**Manifest 字段（实际）**：`ID` / `Name` / `Version` / `Description` / `Protocol` / `Community` / `Command` / `Cwd` / `Env` / `TimeoutMS` / `Concurrency` / `Actions` / `Address` / `Provides` / `Requires`，另有运行时字段 `Dir`。

- `ParseManifest` 校验：id 正则、version `^\d{1,4}\.\d{1,4}\.\d{1,4}$`、protocol 白名单、command/address 条件、cwd 不含 `..`、timeout 1–120000、concurrency 默认 `concurrent`、action name 正则、provides/requires 正则去重；未知字段忽略。

**三种适配器**：

| 适配器 | 注册键 | 协议消息 |
| --- | --- | --- |
| `NativeAdapter` | `gqy-jsonrpc-v1` | `initialize`（params protocol）→ `call`（`{action, arguments}`，取 `result.content`）→ `shutdown` |
| `MCPAdapter` | `mcp` | `initialize`（protocolVersion `2024-11-05`、capabilities `{}`、clientInfo）→ `notifications/initialized` → `tools/list` → `tools/call`（`{name, arguments}`，content[] 文本拼接，isError 报错）→ `shutdown` |
| `RemoteAdapter` | `unix` | 连接 unix / tcp，`initialize` → `call` → `shutdown` 后关连接，不杀远程进程 |

**生命周期**：状态 `discovered / loading / ready / closing / failed`；`Load` 幂等、`Unload` 幂等、崩溃置 `failed` 不重启；`Scan` 扫描 `$GQY_HOME/plugins/<id>/manifest.json`，同版本且非 failed 不重启。

**并发**：concurrent 直接并发；single-channel / exclusive 用 `sem`（容量 1）排队；`transport` 用「请求序号 → 等待通道」多路复用（8 MiB 缓冲），晚到 / 未知 id 丢弃。

**进程回收**（proc_unix）：`Setpgid` 独立进程组；Close = 关 stdin → 等 5s → SIGTERM → 等 2s → SIGKILL；stderr 追加到 `$GQY_HOME/plugins/<id>.log`。

**工具名**：`ToolName(pluginID, action)` = `pluginID__action`，非字母数字转 `_`，最长 64。

**实现与蓝图差异 ③（已修）**：`RemoteAdapter` 现同时注册在 `unix` 与 `tcp` 键下，tcp 远程插件可用（只连不拉起、不杀远程进程）。
**实现与蓝图差异 ④（已修）**：加载失败回滚到 `discovered` 并清空 impl/pid，同 id 可重试加载；`Unload` 对 `failed` 实例会清理摘除。

### 3.5 /api/plugins*（app/internal/httpapi/plugins.go）

| 方法 + 路径 | 请求体 | 响应 |
| --- | --- | --- |
| `GET /api/plugins` | — | `{"plugins":[PluginStatus…]}` |
| `POST /api/plugins/reload` | — | `{"ok":true,"plugins":[…]}` |
| `POST /api/plugins/{id}/load` | — | `{"ok":true,"plugins":[…]}` |
| `POST /api/plugins/{id}/unload` | — | `{"ok":true,"plugins":[…]}` |
| `POST /api/plugins/{id}/call` | `{action, arguments}` | 成功 `{"ok":true,"content":"…"}`；失败 `{"ok":false,"error":code,"message":"…"}`（HTTP 200） |

`PluginStatus` 字段：`id` / `name` / `version` / `protocol` / `state` / `concurrency` / `pid` / `started_at` / `calls` / `failures` / `last_error` / `actions` / `provides` / `requires`。

`pluginErrCode`：`not_found` / `not_ready` / `timeout` / `canceled` / `call_failed`。

**实现与蓝图差异 ⑤（已修）**：`call` 响应补 `duration_ms`（成功与失败都带）。

### 3.6 一次性插件（app/internal/oneshot + app/cmd/gqy-run）

**来源解析** `ParseSource`：

- 本地路径：直接使用。
- git：`git+<url>@<ref>` 或 `<url>#<ref>`。
- url：`https://…`（带 `#` 时按 git 解析）。
- 注册表：`reg:<name>` 或 `<name>@<version>`，读 `$GQY_HOME/oneshot-registry.json`。

**manifest**：复用 `plugin.ParseManifest`，另取 `mode` / `hash` / `source`；`mode` 必须 `oneshot`；`protocol` 只允许 `gqy-jsonrpc-v1` / `mcp`；`hash` 形如 `sha256:<64 位小写 hex>`。

**拉取** `pull`：

- local：`copyTree`。
- git：`git clone` + `checkout <ref>` + `rev-parse HEAD`（哈希 = commit SHA）。
- url：下载后对 `.tar.gz` / `.tgz` / `.tar` 解包，哈希 = sha256。
- registry：按 name/version 找条目，下载解包后与条目 `sha256` 比对。

**目录**：`$GQY_HOME/tmp/oneshot/<id>-<run>/`（工作目录）；`$GQY_HOME/tmp/oneshot/.cache/<id>-<version>/`（缓存，带 `.cache.json`）。

**执行**：

- 声明 `run` 动作：`rpc.call` 发 `{"jsonrpc":"2.0","id":1,"method":"call","params":{"action":"run","arguments":{…}}}`。
- 未声明：直接跑 `command`，参数以 stdin 单行 JSON 传入，stdout 为结果。
- 进程回收沿用 plugin 时序（EOF → 5s → SIGTERM → 2s → SIGKILL）。

**产物收集**：`out/stdout.txt`（直接 command 模式）、`out/result.json`（content 可解析为对象时）、`out/files/`（result JSON 带 `files` 数组时）。

**清理与缓存**：默认 `RemoveAll` 工作目录，`--keep` 保留；失败也清理（keep 除外）；缓存命中比对 `.cache.json` 的 hash；TTL 清理由 `storage.CleanOneshotCache`（默认 7 天）。

**CLI**：`gqy run <来源> --args '<json>' --keep --no-cache --id <id>`，输出 `Result` JSON。

**实现与蓝图差异 ⑥**：url 源只支持 tarball，blueprint/oneshot.md 写「tarball 或单文件」。
**实现与蓝图差异 ⑦**：注册表文件位置 `$GQY_HOME/oneshot-registry.json` 为实现新定（blueprint 未指定）。

**关闭回收（019）**：`plugin.Manager.Close(ctx)` 关闭全部已加载插件并回收进程组，幂等、错误聚合；`gqy-server` 在信号与异常退出路径都调用它。

**已修 bug（施工 012 端到端发现）**：插件进程原用 `exec.CommandContext(请求 ctx)` 拉起，HTTP load 请求结束后请求 ctx 取消会 SIGKILL 子进程（load 成功、随后 call 报 `broken pipe`）。现改为进程生命周期只由 `Close` 管（`exec.Command`），并补回归测试 `TestPluginProcessSurvivesLoadContextCancel`。

## 4. 边角情况（实现里真实处理）

- read：目录报错、超限报错、符号链接逃逸 / 拒绝路径被拒、图片转 data URI。
- edit：写目标符号链接拒绝、原子写不产生半截文件、保留原权限、自动建父目录。
- shell：超时杀进程组、输出截断带标记、白名单拒绝元字符与未列入命令。
- registry：重名注册报错；注销不存在返回 `ErrNotFound`（幂等）。
- plugin：manifest 校验失败整体拒绝；重复 id 跳过；加载失败置 failed；崩溃不重启；晚到响应丢弃。
- oneshot：拉取失败无残留；哈希不匹配拒绝；`--keep` 保留；缓存命中复用；失败不写缓存。

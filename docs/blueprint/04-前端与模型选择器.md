# 04 · 前端与模型选择器

**状态**：已实现（2026-11-02，施工 010 落地）

**对应设计决定**：FE1–FE9（10-前端界面）、MD1–MD6（13-模型资料与选择器）。

- FE1 零构建：`index.html` + 原生 JS 模块 + CSS，Go 静态托管，无构建链。
- FE2 视图与浮层：对话/看板两个视图；设置、用量、扩展、灯箱、引导是浮层。
- FE3 页面清单与职责（各页数据来源见下表）。
- FE4 五种 SSE 事件按序重建消息块；非流式 = 流式拼接。
- FE5 渲染细节：thinking 默认折叠、tool 轨迹带参数/输出/耗时/状态、ask_user 卡片、产物灯箱。
- FE6 草稿/停止/重试：草稿按会话、停止保留增量标 canceled、重试不覆盖历史。
- FE7 附件上传：拖拽+选择，文本注入/图片多模态/二进制落盘。
- FE8 本地存储只放 UI 偏好，不存密钥与正文。
- FE9 鉴权：请求自动带 cookie/Bearer，前端不存密钥。
- MD1 模型资料权威是 providers.json；公开目录只补全展示，不驱动路由。
- MD2 capabilities 六字段：tool_call / vision / thinking / reasoning_effort / context_window / max_output。
- MD3 资料是派生缓存、可重建；CF 快照只含配置。
- MD4 `/v1/models` 的 provider 条目带 capabilities，路由组不带。
- MD5 选择器交互：搜索、能力/供应商过滤、分组、最近使用、默认标记、键盘导航、选择立即生效。
- MD6 后端支撑：一次拿全能力；缓存落 `$GQY_HOME/cache`（可删重建）。

## 具体形状

### 静态资产与托管

| 文件 | 内容 |
| --- | --- |
| `app/index.html` | 单页骨架：侧栏、消息区、输入区、选择器/浮层挂载点 |
| `app/demos.html` | 组件形态演示页（仅本地查看） |

| `app/styles/`（5 个） | `app/base/tokens/themes/demos` |

- `httpapi.static.go` 的 `SetWebDir(dir)` 设置前端目录（`main.go` 的 `resolveWebDir()` 决定；空 = 不提供 UI）。
- 路由 `GET /` 回退到 `/index.html`；扩展名白名单：`.html .css .js .mjs .svg .png .jpg .jpeg .webp .ico .woff2`。
- 每次请求都过 `storage.EnsureInside(webDir, full)`，防目录穿越。

### 五种 SSE 事件 → DOM（chat.js）

消息占位结构：`{ thinking: "", content: "", tools: [], question: null }`。

| 事件 | DOM 行为 |
| --- | --- |
| `thinking` | `placeholder.thinking += event.delta`，默认折叠、可展开 |
| `tool` | 追加到 `placeholder.tools`（参数/输出/耗时/状态） |
| `text` | `content` 增量追加 |
| `question` | 渲染 ask_user 卡片：选项按钮 + 自定义输入（`data-question-input`），提交按钮 `data-question-submit` |
| `branch` | 支线卡片（`data-branch-id`）：原消息 + 支线回答 + 「采纳进主线」按钮（`data-branch-adopt`），已采纳显示徽标 |
| `done` | 结束本轮，展示用量与停止原因（`usage` / `stop_reason`） |

### localStorage 键（只有 UI 偏好）

`gqy.model`、`gqy.recentModels`、`gqy.theme`、`gqy.reduceMotion`、`gqy.board`、`gqy.onboarded`。

密钥、token、消息正文都不落 localStorage（FE8 / 08 A8）。

### `/v1/models` capabilities（models.go 实际形状）

```json
{
  "object": "list",
  "data": [
    {
      "id": "deepseek/deepseek-chat",
      "object": "model",
      "owned_by": "deepseek",
      "created": 0,
      "display_name": "DeepSeek · deepseek-chat",
      "default": true,
      "capabilities": {
        "tool_call": false,
        "vision": false,
        "thinking": false,
        "reasoning_effort": [],
        "context_window": 0,
        "max_output": 0
      }
    },
    {
      "id": "group/daily",
      "object": "model",
      "owned_by": "group",
      "created": 0,
      "display_name": "日常",
      "members": ["deepseek/deepseek-chat"]
    }
  ]
}
```

- 布尔缺省 false、数值缺省 0、`reasoning_effort` 缺省空数组 = 未知；路由组不带 capabilities。
- 当前未接公开目录，能力字段全为未知值（MD3/MD6 后置）。

### 模型选择器（js/picker.js）

导出 `initPicker()` / `renderPicker()` / `applyModel(id)`；挂载 `#modelPickerWrap`。

| 交互 | 实现 |
| --- | --- |
| 搜索 | `#modelPickerSearch` 实时过滤模型 id / 名称 |
| 能力过滤 | `#pickerCaps`（按 capabilities 勾选） |
| 供应商过滤 | `#pickerVendor`（下拉） |
| 分组 | provider 模型段 + 路由组段 |
| 最近使用 | 读 `gqy.recentModels` 排前 |
| 默认标记 | 条目 `default: true` 显示默认徽标 |
| 键盘 | ↑（`ArrowDown` 反向）、↓、Enter 选中、Esc 关闭 |
| 生效 | `applyModel(id)` 写 `gqy.model` 并刷新当前会话模型 |

## 边角情况

- 未挂载 Web UI（`webDir` 为空）：所有静态路径 404。
- 非白名单扩展名（如 `.json`）：404，不暴露数据文件。
- 路径穿越（`../` 或符号链接逃逸）：`EnsureInside` 拒绝，404。
- 流中断未收到 `done`：保留已收到增量并标记「不完整」，不假装成功。
- 选择器无模型（providers 为空）：显示空态提示，不报错。
- 无 `/v1/models` 权限（未设置 token 且非本机）：选择器显示占位，不阻塞对话。
